# IBL 烘焙：摩尔纹(Aliasing)现象与立体角预滤波消除法

在自建 Compute Shader 执行环境光漫反射（Irradiance）球面积分时，如果原全景图（HDR）分辨率极高，且在积分循环中对 Mip 0 级别强行离散采样，会导致输出的 Cubemap 表面出现规律性的**摩尔纹（高频噪点走样）**现象。

## 1. 产生摩尔纹的核心原因（欠采样）

计算 Irradiance 的本质是累加半球上一系列离散方向（由步长 `sampleDelta` 控制）上的像素光辐射。
这是一个典型的**低通滤波（模糊）**过程。但计算机只能通过有限个点来近似连续积分。

假设原天空盒边长达 2048、4096，像素极其密集；而积分时你在半球面上只采了 1000 - 3000 个点。
这就意味着：**每次采样跃过的距离（步长）远大于甚至直接跨越了数百个像素**。
这样会导致大量高对比度的细节（例如树叶边缘、烈日边缘）从宏观积分视野中被“漏掉”或者“撞上”。微小的法线偏移就会采样到差异巨大的颜色亮度。最终结果表现为交错锯齿（摩尔纹），数学学名叫做**频率混叠（Aliasing）**。

## 2. 为什么自己拍的低清水准图无摩尔纹？

如果使用自己搭建的 128x128 甚至 512x512 的相机捕捉 Cubemap 进行直接烘焙，可能不会出现摩尔纹。
这是因为低分辨率图像在其自身存取时像素跨度就很大，硬件纹理过滤会自动将邻近数据均匀。你的步长恰与较低频的像素区域密度接近，掩盖了走样现象。但这属于一种凑巧。要解决根本问题，不能依赖降低环境贴图品质。

## 3. 标准图形学解法：立体角映射与 MipMap

工业级解法，必须通过采集合适层级的 **Mip Map** 替代最高级别（Mip 0）进行插值积分。
即用 GPU 硬件自带的双线性插值先将过于密集的图“预糊”，避免积分点间存在未采样盲区。

### 立体角（Solid Angle）匹配法则
核心目的：让**每一个采样点“代表”的面域大小**，近似等于**所采样 Mip 层单像素代表的面积**。

1. **单个 HDR Mip 0 像素的立体角（$\Omega_{texel}$）**：
   完整的 360 度圆球覆盖 4π 个球面度。对于分辨率长宽为 W 的 Cubemap，这 4π 被分散给了 6 面，以及面的 W * W 个像素。
   $\Omega_{texel} = \frac{4\pi}{6 \times W^2}$

2. **你步长离散出的单采样点的立体角（$\Omega_{sample}$）**：
   半球积分覆盖 2π 个球面度，假设内外层（\(\phi, \theta\)）共采样了 $N_{total}$ 个离散点。
   $\Omega_{sample} = \frac{2\pi}{N_{total}}$

3. **求理想的 Mip 降级（Level $L$）**：
   原像素太小（$\Omega_{texel} < \Omega_{sample}$），为了填满盲区，必须从下一级 Mip 中取图。
   每一级 Mip 宽和高像素减半，即面积扩大 4 倍。因此所需层数 $L$：
   $L = 0.5 \log_2 \left( \frac{\Omega_{sample}}{\Omega_{texel}} \right)$

### 4. 落地步骤

1. 被烘焙的原 HDR 资源设置中，勾选 `Generate Mip Maps`。
2. 确保在 Compute Shader 中使用自带的三线性/双线性纹理采样器：
   ```hlsl
   SamplerState sampler_Skybox;
   ```
3. 在 CS 中提前算出 `mipLevel`：（由于是漫反射，可以添加一点常量 +1 bias，让整体更平滑）
   ```hlsl
   float mipLevel = 0.5 * log2(saSample / saTexel) + 1.0; 
   irradiance += _Skybox.SampleLevel(sampler_Skybox, lightDirWS, mipLevel).rgb * cos(theta) * sin(theta);
   ```

## 5. 剩余微量瑕疵问题
如果加了 Mip 后图上依然带有微弱类似细沙或经纬网样的不平整，那是**点阵分布极化**导致：利用规律的嵌套 `for (phi) for (theta)` 会把采样点全扎堆在极点，产生伪影偏差。
终极的商业级消除方案通常会使用 **Hammersley 等面积序列（重要性采样 / Monte Carlo）** 把采样点随机又均匀地打散在半球上。对于学习原理解方程，MipMap + 立体角计算已足以覆盖知识盲区。
