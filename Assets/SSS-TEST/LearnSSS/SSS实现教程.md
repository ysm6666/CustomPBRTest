# 屏幕空间次表面散射（SSS）实现教程：从 BSSRDF 积分到 URP 代码

用普通漫反射给角色皮肤着色，即使肤色和高光都调对了，皮肤也可能仍像一层涂料：明暗交界缺少皮肤特有的柔和、偏暖的过渡。原因之一是，普通漫反射只在当前表面点计算光照，没有描述光进入皮肤后，在内部散射、再从附近位置出来的过程。

本教程从这个差别出发，介绍一种适合实时渲染的实现：先把漫反射光照存成纹理，再按光在皮肤中扩散的范围混合邻近位置的光照，最后加回表面高光。这个方法叫**屏幕空间次表面散射**。它主要处理可见表面附近的散射；耳朵逆光透亮还涉及另一侧的入射光与厚度，不是把这张纹理模糊得更宽就能解决的。

阅读前，需要了解 Unity Shader 中的法线、`N·L`、纹理采样，以及 Render Texture（RT，一张可以接收渲染结果的纹理）。不要求事先了解 BSSRDF 或重要性采样：它们会在需要时引入。文中的积分用来表达“把许多小块的贡献加起来”，涉及的关键计算会展开说明。

前半篇回答“为什么这样算”，后半篇把这些量对应到 URP 的 Pass 和代码。读完后，应当能够解释散射权重的来源、RGB 为什么使用不同散射距离，以及为什么高光要与漫反射分开处理。

> 本教程配套代码：
> - `Assets/SSS-TEST/SSSBurley/SSSBurleyLit.shader`：材质 Shader
> - `Assets/SSS-TEST/SSSBurley/SSSBurleyFilter.shader`：散射滤波 Shader
> - `Assets/SSS-TEST/SSSBurley/SSSBurleyFeature.cs`：Renderer Feature
>
> 实现采用 Burley 扩散剖面与圆盘重要性采样，思路参考 Unity HDRP 的 `SubsurfaceScattering.compute`，在 URP 中组织渲染流程。

## 1. 总览：SSS 到底在做什么

想象一束光照在皮肤上，形成一块亮区。取亮区内的一点 A，再取紧挨着它、落在阴影里的一点 B。

普通漫反射会分别计算两点：A 收到光，因此较亮；B 没有收到这束直射光，因此没有这部分直接光贡献。即使 A 就在旁边，A 收到的光也不会通过这个局部着色模型传给 B。

真实皮肤不同。一部分光从 A 进入后，在内部多次改变方向，其中一些会从 B 附近出来。B 因而可能比普通漫反射算出的结果更亮，明暗交界也会变得柔和。这个“入口和出口不在同一点”的过程，就是这里要模拟的**次表面散射**，简称 SSS。

这给实现提供了一个方向：计算 B 时，不能只看 B 自己受到多少光，还要考虑附近各点进入的光。但邻居的贡献不能全算一样大：距离越远，通常贡献越小；不同颜色的光，扩散范围也不同。后文要找的，就是描述这些贡献的权重。

在屏幕空间实现中，我们用可见像素代表表面点，把上述计算近似成对邻近漫反射光照的加权混合。相机看不见的表面没有存进这张图，后续滤波也就无法直接读取它们。

先看渲染流程，暂时不用记住每一步的公式：

```
 ┌─────────────────┐    ┌──────────────────┐    ┌──────────────────┐    ┌──────────────────┐
 │ 步骤一           │    │ 步骤二           │    │ 步骤三           │    │ 步骤四           │
 │ 画漫反射光照     │ →  │ 屏幕空间加权模糊 │ →  │ 存成 SSS 结果 RT │ →  │ 前向 Pass：      │
 │ 到 Diffuse RT    │    │ （Burley 权重）  │    │                  │    │ 结果 + 高光      │
 │ + 参数 + 深度    │    │                  │    │                  │    │                  │
 └─────────────────┘    └──────────────────┘    └──────────────────┘    └──────────────────┘
```

| 步骤 | 目的 | 对应理论 |
|---|---|---|
| 一：画 Diffuse RT | 先把"每个点接收了多少光"存下来，模糊时要读邻居的值 | 第 5、6 节 |
| 二：加权模糊 | 用 Burley 剖面做权重，计算"周围的光扩散过来多少" | 第 7~12 节 |
| 三：存结果 | 后面的前向 Pass 要读它 | — |
| 四：合成 | 高光发生在皮肤表面，不参与散射，最后单独加上 | 第 3 节 |

下面先把理论讲通，再落到代码。

# 第一部分：理论——从积分公式到工程公式

## 2. 起点：BSSRDF 渲染积分

现在把刚才的 A、B 换成可以用于任意表面点的记号。我们要计算的出口点记为 $p_o$，一个可能的入口点记为 $p_i$。下标 $o$ 来自 outgoing（出射），$i$ 来自 incoming（入射）。观察方向记为 $\omega_o$，入口处指向光源的方向记为 $\omega_i$。

固定出口 $p_o$ 后，要做两次累加：

1. **先看一个入口。** 这个入口可能同时接收灯光、天空光等不同方向的光，需要累加这些方向各自对出口的贡献。
2. **再换其他入口。** 不只有一个位置能把光传到出口，因此还要累加整个表面上不同入口的贡献。

每份入射光对出口有多大影响，由一个函数 $S$ 描述。它同时接受入口位置、入口方向、出口位置和出口方向，叫作 **BSSRDF**（双向次表面散射反射分布函数）。先不必记住全称，记住它比局部 BRDF 多考虑了“光从哪个位置进入”。

用积分写出这两次累加，就是：

$$
L_o(p_o,\omega_o) = \int_{\mathcal{A}} \int_{\Omega} S(p_o,\omega_o,p_i,\omega_i)\, L_i(p_i,\omega_i)\, \cos\theta_i \, d\omega_i \, dA
$$

这里 $L_i$ 是入射辐亮度，$L_o$ 是向观察方向出射的辐亮度。它们描述特定方向上的光，而不是整块表面收到的总光量。此处的 $L_o$ 只计算次表面贡献，表面高光之后另加。

从里往外读这个式子：

- $L_i\cos\theta_i\,d\omega_i$：入口从一小片方向收到的光照贡献。$\theta_i$ 是该方向与**入口处法线**的夹角；斜着照时，光铺到更大的面积上，所以有与普通漫反射 `N·L` 相同的余弦投影因子。
- 乘上 $S$：计算这份光对指定出口、指定观察方向的影响。
- $\int_\Omega$：累加入口外侧半球上的方向；$\Omega$ 随入口处法线确定。
- $\int_{\mathcal A}\dots dA$：再累加物体整个表面上各小块面积的贡献。

$S$ 可以直观地理解成“传递权重”，但不是一个 0 到 1 的普通比例：它描述的是单位面积、单位立体角的分布，需要配合积分才得到出射光。这也是名字里带“分布函数”的原因。

这个方程说明了要算什么，却还没告诉我们怎样快速算。直接细分所有入口、所有方向，成本对本教程的实时实现过高。接下来先简化 $S$，再把积分变成有限次纹理采样。

## 3. 拆开 BSSRDF：进、传、出

如果逐条追踪光在皮肤内部的路径，就必须处理大量散射和吸收事件。实时实现通常不追踪这些路径，而是问一个更容易处理的问题：**光经过内部传播后，会以怎样的分布从表面出来？**

先考虑材质均匀、表面局部较平、物体足够厚的情况。“足够厚”是相对于光的扩散范围而言的：我们暂时不处理光从另一面穿出的情况。在这类近似中，可以用入口与出口的距离来描述空间扩散，再单独处理进出表面的方向影响：

$$
S(p_o,\omega_o,p_i,\omega_i) \approx \frac{1}{\pi}\, F_t(\omega_o)\; \big[\rho\, R(r)\big]\; F_t(\omega_i)
$$

这里 $r=\lVert p_i-p_o\rVert$ 是两点间的直线距离，不是光在内部曲折路径的总长度。我们没有求出每条路径，而是把许多路径共同造成的结果近似成一个距离函数。

按“进、传、出”看这几个因子：

| 项 | 在模型中负责什么 |
|---|---|
| $F_t(\omega_i)$ | **进**：表面反射掉一部分光，余下部分进入内部。用 $F$ 表示菲涅尔反射率时，透射比例写为 $F_t=1-F$ |
| $\rho R(r)$ | **传**：$R(r)$ 描述单位表面积上的扩散分布；$\rho$ 是漫反射反照率，控制各颜色通道的总量 |
| $F_t(\omega_o)$ | **出**：近似描述出射边界的透射影响；并非到达表面内部的光都能离开 |
| $1/\pi$ | 对应 Lambert 型的出射角度分布，与普通漫反射 BRDF 中的 $1/\pi$ 有相同来源 |

为什么会出现 $1/\pi$？如果出射辐亮度不随方向变化，把它在半球上按余弦投影累加，会得到一个 $\pi$ 因子。除以 $\pi$ 就完成这一角度分布的归一化。这里额外加入了边界透射因子，因此不能仅凭这个 $1/\pi$ 就断言完整模型已经能量守恒；后续实时实现还会近似处理这些边界项。

这个分解是本文采用的近似形式，**不是任意 BSSRDF 都必须满足的定义**。例如薄耳朵同时涉及正反两面，用单个厚介质反射剖面就不够了。正文先完成同侧散射，再讨论适合屏幕空间实现的进一步简化。

有些资料把包含颜色的空间剖面记为 $R_d(r)$。本文把它写成 $\rho R(r)$，是为了区分“扩散到多大范围”和“最终有多少各色光”，也为第 6 节讨论颜色贴图放在滤波前还是滤波后做准备。

**这也解释了为什么要把高光分开。** 在这里使用的材质模型中，表面镜面反射那部分光没有进入内部，不应跟着皮下漫反射一起扩散。如果把已经合成高光的整张画面模糊，高光也会被抹开；所以前面的流程先处理漫反射，最后再加表面高光。

## 4. 扩散剖面 R(r)：Burley Normalized Diffusion

### 4.1 公式

上一步把内部传播交给了 $R(r)$，但还没有给它具体形状。可以这样理解它：在一个均匀介质的平面表面上，把一小束光照在一个位置，观察光从周围表面出来的分布。只看离照射中心的距离，就得到一条从中心向外衰减的曲线，称为**扩散剖面**。

本文选用 Burley 归一化扩散剖面：

$$
R(r) = \frac{e^{-r/d} + e^{-r/(3d)}}{8\pi\, d\, r}
$$

先只看一个颜色通道：

- $r$ 是入口和出口的直线距离，本文以毫米表示。
- $d>0$ 是控制扩散宽度的长度参数，也以毫米表示。$d$ 越大，光分布到的范围越宽。
- $e^{-r/d}$ 随距离下降较快，$e^{-r/(3d)}$ 下降较慢。两项组合，使曲线同时具有靠近中心的集中部分和延伸较远的尾部。
- 分母负责把这个形状变成归一化的面积分布，下一节会实际算出它的总量。

$r/d$ 没有单位，因此把 $r$ 和 $d$ 同时换成另一种一致的长度单位，不会改变指数的值。实现中若一个量用米、另一个用毫米，扩散范围就会出错。

这个曲线形式用于拟合光传输模拟得到的反射分布。我们采用它，是因为它足够简洁，能表现集中与长尾的扩散形状，而且可以积分和采样，适合后续实现。

实际着色时，RGB 三个通道分别使用 $d_R,d_G,d_B$。例如设置红色通道的 $d_R$ 比另两个通道大，亮侧的红光就能影响更远的暗侧位置，明暗交界便会出现偏红的过渡。

### 4.2 先弄清楚：我们要加起来的是什么？

第 3 节把空间传播写成了 $\rho R(r)$：$\rho$ 控制各颜色通道的总量，$R(r)$ 负责把这份总量分布到周围。现在先固定一个颜色通道，把交给 $R$ 分配的总量记成 1。我们希望改变 $d$ 时，改变的是这 1 份的分布范围。

例如，一份总量可以分成近处 0.6、中间 0.3、远处 0.1；也可以分成近处 0.3、中间 0.4、远处 0.3。两种分布加起来都是 1，后一种分得更远。这些数字只是说明“分布”的含义，尚未代入 Burley 公式。

接下来要检查的就是：**用 Burley 的 $R(r)$ 分配后，把整个表面上的份额收集回来，是否恰好得到 1？**

#### 从一小块表面的份额开始

把周围表面切成很多小块。对其中一块，需要知道两件事：它离中心多远，以及它有多大。

$R(r)$ 给出距离 $r$ 处**每单位面积分到的份额**。因此，一小块表面分到的份额约为：

$$
\text{小块的份额} \approx R(r)\times\Delta A
$$

这里 $\Delta A$ 是小块的面积。如果一小片区域内 $R$ 近似为 $0.02\,\text{mm}^{-2}$，那么其中 $1\,\text{mm}^2$ 分到约 0.02，$3\,\text{mm}^2$ 分到约 0.06。可见，计算这一片的份额，需要把 $R$ 与面积相乘。

把每块的份额加起来，就是整个表面分到的总量。小块切得足够细，求和便写成面积极分：

$$
\text{总份额}\approx\sum_j R(r_j)\,\Delta A_j
\quad\longrightarrow\quad
\int R(r)\,dA
$$

此时，积分的目的已经确定了：收集所有小块分到的份额。下面只是选择一种方便的切块方法。

#### 为什么按圆环来加？

在这个平面模型中，$R$ 只取决于距离。距离中心同样远的位置，使用同样的 $R$ 值。因此，可以把平面分成一圈圈很薄的圆环，一整圈一起计算。

半径为 $r$、宽度为 $\Delta r$ 的薄圆环，面积近似为“周长 × 宽度”：

$$
\Delta A_{\text{ring}}\approx 2\pi r\,\Delta r
$$

所以，这一圈分到的份额约为：

$$
R(r)\times 2\pi r\,\Delta r
$$

这一步里的 $2\pi r$ 很重要。同样宽的圆环，半径越大，包含的小块越多。外圈每单位面积的份额虽然更低，但整圈的份额还取决于整圈有多大。

让圆环宽度趋近于零，再从中心向外累加所有圆环，就得到：

$$
\text{总份额}=\int_0^\infty R(r)\,2\pi r\,dr
$$

这就是后面要计算的积分。$R(r)$ 决定各处的分配密度，$2\pi r\,dr$ 给出这一圈的面积，两者相乘得到一圈的份额。

#### 与极坐标写法接起来

如果再把一个圆环按角度分成小片，每片的弧长是 $r\,d\theta$，宽度是 $dr$，面积便是：

$$
dA=r\,dr\,d\theta
$$

把角度 $\theta$ 从 0 加到 $2\pi$，这些小片就拼成整个圆环。因此，下列两个写法表达的是同一次累加：

$$
\int_0^{2\pi}\!\int_0^\infty R(r)\,r\,dr\,d\theta
=\int_0^\infty R(r)\,2\pi r\,dr
$$

左边逐片累加，右边先把同一圈的小片合起来。选用极坐标，是因为它让“同距离、同权重”的圆环更容易计算。

### 4.3 算出总份额，理解“归一化”

现在代入 Burley 公式，检查所有圆环的份额加起来是多少：

$$
\begin{aligned}
\text{总份额}
&=\int_0^\infty R(r)\,2\pi r\,dr\\
&=\int_0^\infty
\frac{e^{-r/d}+e^{-r/(3d)}}{8\pi d r}\,2\pi r\,dr\\
&=\frac{1}{4d}\int_0^\infty
\left(e^{-r/d}+e^{-r/(3d)}\right)dr
\end{aligned}
$$

分母的 $r$ 与圆环面积中的 $r$ 抵消，$2\pi/(8\pi)$ 化为 $1/4$，于是只剩下两个指数函数的积分。

对于正数 $a$，指数函数的积分是：

$$
\int_0^\infty e^{-r/a}\,dr
=\left[-a\,e^{-r/a}\right]_0^\infty=a
$$

第一项取 $a=d$，得到 $d$；第二项取 $a=3d$，得到 $3d$。所以：

$$
\text{总份额}=\frac{1}{4d}(d+3d)=1
$$

这回答了第 4.2 节的问题：**对于任意 $d>0$，Burley 剖面分到整个平面上的份额恰好是 1。** 这就叫“归一化”。当 $d$ 增大，份额会分到更远的地方，同时分布也会摊薄，总份额保持不变。

回到 $\rho R(r)$：假设这个颜色通道的 $\rho=0.6$，那么它的空间剖面积分就是：

$$
\int \rho R(r)\,dA=0.6\times 1=0.6
$$

现在两者的分工就清楚了：$\rho$ 决定这份空间剖面的总量，$d$ 决定它分布的宽度。这里暂时把颜色视为处处相同；颜色贴图变化时如何处理，会在第 6 节讨论。

#### 这和后面的纹理滤波有什么关系？

回想普通加权平均。三个位置的光照都是 10，用权重 0.6、0.3、0.1 混合，结果是：

$$
0.6\times10+0.3\times10+0.1\times10=10
$$

换成另一组总和为 1 的权重，结果仍是 10。只有各位置的光照不同，重新分配权重才会改变结果。

平面上的扩散滤波遵循同样的道理。设待滤波的光照处处为 $I_0$，将所有位置的光照按 $R$ 混合：

$$
\int R(r)\,I_0\,dA
=I_0\int R(r)\,dA
=I_0
$$

因此，归一化给了后续实现一个检查方法：**在均匀输入、相同散射参数的理想平面上，调整散射宽度，滤波前后的亮度应保持一致。** 当输入有明暗变化时，滤波才会重新混合这些位置的光照，产生我们希望看到的柔和过渡。

到这里，$R$ 的作用已经落实了：它给出各处的空间权重，乘面积得到每块的份额，所有份额加起来为 1。下一节将处理方向上的光照累加，把每个入口受到的光存进纹理，供这样的空间滤波使用。

## 5. 近似一：把方向积分"提前算好"

第 4 节解决了“附近一块表面对出口有多大权重”，现在还缺这块表面收到多少光。比如脸颊上的入口 A 同时受到主光和天空光照射：我们可以先把 A 收到的光加起来，存成一个 RGB 值；计算出口 B 时，只需读取这个值，再乘 A 到 B 的空间权重。这样就不必为每个出口重新计算入口的全部灯光。

下面把这个想法写成公式：先固定入口、累加方向，再移动入口、累加位置。关键是弄清哪些因子在当前这次累加中不变。

### 5.1 前提知识

**前提知识 1：与积分变量无关的因子可以提到积分号外面**

积分 $\int g(x)\,dx$ 里只有积分变量 $x$ 在变。不含 $x$ 的因子 $c$，对这个积分来说就是常数：

$$
\int c\cdot g(x)\,dx = c\int g(x)\,dx \qquad (c \text{ 与 } x \text{ 无关})
$$

原因：积分本质上是"切成很多小块，每块的值乘以宽度再求和"。每一块都乘了同一个 $c$，提公因式即可。

**前提知识 2：嵌套积分从里往外算**

$\displaystyle\int_{\mathcal{A}}\left[\int_\Omega \cdots\, d\omega_i\right] dA$ 的计算顺序是：

1. 先**固定**一个入射点 $p_i$，在内层对所有入射方向 $\omega_i$ 积分，得到一个只和 $p_i$ 有关的值；
2. 再让 $p_i$ 走遍整个表面 $\mathcal{A}$，在外层把这些值积分起来。

由此得到三条规则：

- **内层积分**里 $p_i$ 是固定的，只有 $\omega_i$ 在变。只依赖 $p_i$、不依赖 $\omega_i$ 的因子，对内层是常数，可以从内层提到外层。
- **外层积分**里只有 $p_i$ 在变。不依赖 $p_i$ 的因子，可以提到最外面。
- $p_o$ 和 $\omega_o$ 是"当前要算的像素"和"当前视线方向"，整个计算过程中都不变，**它们不是积分变量**。

### 5.2 逐步代入

**第 1 步：写出原式（第 2 节）**

$$
L_o(p_o,\omega_o) = \int_{\mathcal{A}} \int_{\Omega} S(p_o,\omega_o,p_i,\omega_i)\, L_i(p_i,\omega_i)\, \cos\theta_i \, d\omega_i \, dA
$$

**第 2 步：把 $S$ 原样替换成第 3 节的拆分式**

$$
S(p_o,\omega_o,p_i,\omega_i) = \frac{1}{\pi}\, F_t(\omega_o)\, \rho\, R(r)\, F_t(\omega_i)
$$

直接放进去，此时什么都不调整：

$$
L_o(p_o,\omega_o) = \int_{\mathcal{A}} \int_{\Omega} \frac{1}{\pi}\, F_t(\omega_o)\, \rho\, R(r)\, F_t(\omega_i)\, L_i(p_i,\omega_i)\, \cos\theta_i \, d\omega_i \, dA
$$

**第 3 步：给每个因子标出"它随谁变化"**

| 因子 | 随 $\omega_i$ 变？ | 随 $p_i$ 变？ | 原因 |
|---|---|---|---|
| $\frac{1}{\pi}$ | 否 | 否 | 纯常数 |
| $F_t(\omega_o)$ | 否 | 否 | 只和出射方向 $\omega_o$ 有关，而 $\omega_o$ 是固定的 |
| $\rho$ | 否 | 暂视为否 | 先假设物体颜色处处相同。颜色随位置变化的情况留到第 6 节 |
| $R(r)$ | 否 | **是** | $r = \lVert p_i - p_o\rVert$，$p_o$ 固定，$p_i$ 一变 $r$ 就变 |
| $F_t(\omega_i)$ | **是** | **是** | 入射透射率依赖入射方向与入口法线的夹角；换入口时法线也可能改变 |
| $L_i(p_i,\omega_i)$ | **是** | **是** | 不同位置、不同方向照来的光都可能不同 |
| $\cos\theta_i$ | **是** | **是** | $\theta_i$ 是 $\omega_i$ 和 $p_i$ 处法线的夹角，两者都影响它 |

按依赖关系分成三组：

- **A 组**（两者都不依赖）：$\frac{1}{\pi}$、$F_t(\omega_o)$、$\rho$
- **B 组**（只依赖 $p_i$）：$R(r)$
- **C 组**（依赖 $\omega_i$）：$F_t(\omega_i)$、$L_i(p_i,\omega_i)$、$\cos\theta_i$

**第 4 步：把 A、B 组提出内层积分**

内层只对 $\omega_i$ 积分。A、B 两组都不含 $\omega_i$，按前提知识 1，从内层积分号里提出来（但仍在外层积分里面）。用中括号把内层积分圈起来：

$$
L_o(p_o,\omega_o) = \int_{\mathcal{A}} \frac{1}{\pi}\, F_t(\omega_o)\, \rho\, R(r) \left[ \int_{\Omega} F_t(\omega_i)\, L_i(p_i,\omega_i)\, \cos\theta_i \, d\omega_i \right] dA
$$

现在中括号里只剩 C 组。

**第 5 步：把 A 组中的 $\frac{1}{\pi}$ 和 $F_t(\omega_o)$ 提出外层积分**

外层只对 $p_i$ 积分。$\frac{1}{\pi}$ 和 $F_t(\omega_o)$ 不含 $p_i$，再提一次，放到最外面：

$$
L_o(p_o,\omega_o) = \frac{1}{\pi}\, F_t(\omega_o) \int_{\mathcal{A}} \rho\, R(r) \left[ \int_\Omega F_t(\omega_i)\, L_i(p_i,\omega_i) \cos\theta_i\, d\omega_i \right] dA
$$

$\rho$ 现在是常数，本来也可以提出去。这里故意把它留在外层积分里面，因为第 6 节它会变成随位置变化的 $\rho(p_i)$，那时就不能提出去了。

**这一串操作的意义**：原来"位置"和"方向"纠缠在同一个二重积分里。整理之后，方向积分被完整地关进了中括号，而中括号**只依赖 $p_i$**。所以可以对每个点单独把它算好、存起来；外层积分只需要读取这些存好的值，再按 $R(r)$ 加权求和。

这就是“先画 Diffuse RT，再做空间滤波”的依据。中括号是方向累加的结果 $E$；实际 RT 还会按下文的约定包含 $1/\pi$ 和一部分 albedo，因此不能直接把 RT 数值等同于 $E$。

### 5.3 中括号就是普通漫反射光照

给中括号起个名字：

$$
E(p_i) = \int_\Omega F_t(\omega_i)\, L_i(p_i,\omega_i)\, \cos\theta_i\, d\omega_i
$$

$E(p_i)$ 就是"$p_i$ 点接收到、并且真正进入皮肤的光"。逐项看：

- $L_i(p_i,\omega_i)$：从方向 $\omega_i$ 照到 $p_i$ 的光，对应 shader 里的 `lightColor × shadow`；
- $\cos\theta_i$：对应 `NdotL`；
- $F_t(\omega_i) = 1 - F$：扣掉被表面反射走的部分（那部分是高光）；
- $\int_\Omega$：把所有方向的光加起来。实时渲染里就是"主光源 + 附加光源 + 环境光"逐个累加。

这正是普通漫反射 shader 每个像素都在算的东西。代入后：

$$
L_o(p_o,\omega_o) = \frac{1}{\pi}\, F_t(\omega_o) \int_{\mathcal{A}} \rho\, R(r)\, E(p_i)\, dA
$$

### 5.4 从方向积分到待滤波的白色光照

最外面的 $F_t(\omega_o)$ 仍随观察方向变化。本文的实时模型不再单独计算这个出射边界因子，取 $F_t(\omega_o)\approx1$。这会舍去边界的角度响应，尤其不能据此准确描述掠射方向或内部全反射。

再定义 $D(p_i)=E(p_i)/\pi$。除以 $\pi$ 是第 3 节 Lambert 型出射分布的换算；它对所有入口都相同，可以放进积分里：

$$
\begin{aligned}
L_o(p_o,\omega_o)
&\approx \frac{F_t(\omega_o)}{\pi}\int_{\mathcal A}\rho R(r)E(p_i)\,dA\\
&\approx \int_{\mathcal A}\rho R(r)D(p_i)\,dA.
\end{aligned}
$$

第一行已经使用第 3 节的 BSSRDF 分离模型，第二行又省略了出射边界项。第 5.2 节中提取常数、重新分组的操作，在采用该模型后是代数恒等变换；用这个模型替代原始 BSSRDF 本身则是近似。因此，第 5.2 节代入模型时写出的等号应在这一模型内部理解。

此时理论上的 $D$ 只依赖入口，滤波不必再保存一份随出射方向变化的数据。它可以理解成白色 Lambert 表面对应的漫反射亮度。接下来需要把这个物理记号接到 Unity 的着色约定上。

### 5.5 在 Unity 里 D 怎么算

本地材质使用如下形式：

```hlsl
float3 D = kdDirect * light.color
         * (light.shadowAttenuation * light.distanceAttenuation * NdotL)
         + kdAmbient * SampleSH(n);
```

主光源贡献先乘距离衰减、阴影和非负的 `NdotL`，再与球谐环境漫反射相加。这里沿用 URP 这些光照函数与 Lambert 着色的数值约定，不再额外除一次 $\pi$；不能把已经用于 Unity 着色的 `light.color` 和 `SampleSH` 输出，直接当成未换算的物理辐照度再次处理。

`kdDirect`、`kdAmbient` 用来近似扣除表面反射。本地代码分别以 $V\cdot H$、$N\cdot V$ 求 Schlick 菲涅尔，因此实现中的 $D$ 仍带有视角依赖，不是对第 5.3 节入口半球积分的严格求值。第 16 节会把这些具体取值与理论对应起来。目前先记住数据职责：$D$ 含光照、阴影和这一反射近似，不含 albedo，也不含最终要另加的高光。

### 5.6 用均匀输入检查结果

假设颜色处处为 $\rho$、光照处处为 $D_0$，且采用第 4 节的归一化平面剖面：

$$
L_o=\rho D_0\int R(r)\,dA=\rho D_0.
$$

这和未散射的漫反射值相同。它说明归一化滤波保持常量输入；有明暗变化时，邻居混合才会改变结果。测试 SSS 应看阴影边缘、明暗交界，而不只看均匀受光的白球中央。后面引入屏幕边界、变化的参数和深度权重后，仍应保留这个检查，但它不等于完整光传输的全局能量守恒证明。

## 6. Albedo 放在模糊前还是模糊后

上一节先假设颜色处处相同。现在给脸颊加一颗深色雀斑：如果先乘完整颜色再滤波，雀斑会和光照一起向周围扩散；如果只滤波白色光照，最后才乘当前像素颜色，雀斑边缘会保持清晰。两者控制的视觉结果不同，需要明确颜色贴图在哪一步参与。

用一个 $0\le m\le1$ 的参数分配颜色。对同一个颜色值，有恒等式：

$$
\rho = \rho^{m}\cdot \rho^{1-m}
$$

各通道分别做幂运算。把前一份放在入口、后一份放在出口，得到用于贴图的工程模型：

$$
L_o(p_o) \approx \rho(p_o)^{1-m} \int_{\mathcal{A}} R(r)\, \underbrace{\rho(p_i)^{m}\, D(p_i)}_{I(p_i)}\, dA
$$

例如灰色反照率为 0.36 时，$m=0.5$ 给出两份 0.6，相乘仍是 0.36。一份先影响进入滤波的值，另一份在出口恢复局部纹理对比。颜色随位置变化后，这种分配是控制纹理扩散的近似，不能从“入口和出口各吸收一次”唯一推导出平方根。

| $m$ | 名称 | 效果 |
|---|---|---|
| 1 | Pre-Scatter | 颜色全部参与模糊：颜色渗透最强，但毛孔、雀斑等贴图细节会被糊掉 |
| 0 | Post-Scatter | 只模糊光照，颜色最后乘：细节最清晰，但没有颜色渗透 |
| 0.5 | Pre & Post | 模糊前乘 $\sqrt{\rho}$，模糊后再乘 $\sqrt{\rho}$：两者折中 |

本教程用 $m = 0.5$：Diffuse RT 里存 $I = \sqrt{\rho}\cdot D$，模糊完再乘 $\sqrt{\rho(p_o)}$。

> 验证：当 $\rho$ 处处相同时，$\sqrt{\rho}\cdot\sqrt{\rho} = \rho$，结果和 $m=1$、$m=0$ 一样。三种模式只在贴图颜色有变化的地方有区别。

## 7. 近似二：局部平面 + 极坐标

### 7.1 把附近的表面展开

现在每个入口已有 $I=\rho^mD$，剩下的是把各入口贡献加起来。鼻尖和整张脸都在积分范围内，但 Burley 权重随距离衰减，附近位置通常最重要。若扩散范围相对表面弯曲尺度足够小，可以先把这片表面看成平面。

以出口 $p_o$ 为原点，向右走 2 mm、再向上走 1 mm 能定位一个点；也可以说离原点 $\sqrt5$ mm、沿某个角度前进。后一种就是极坐标 $(r,\theta)$，适合只依赖距离的 $R$。第 4 节已经说明：径向宽度 $dr$、弧长 $r\,d\theta$ 围成的小片，面积为 $r\,dr\,d\theta$。因此：

$$
L_o(p_o)\approx\rho(p_o)^{1-m}
\int_0^{2\pi}\!\int_0^\infty R(r)I(r,\theta)\,r\,dr\,d\theta.
$$

$I(r,\theta)$ 是这个位置存下的光照，不是另一条径向曲线。同一圆环上的各点权重相同，光照却可能一半在阴影、一半在亮处；所以不能像第 4 节检查总量时那样，直接把角度积分替换成 $2\pi I$。

### 7.2 再把平面映到屏幕

局部表面平面和屏幕平面还不是同一个平面。本地实现进一步使用中心深度处、平行于屏幕的平面撒点：毫米偏移换成像素偏移，再读取 Diffuse RT。这样入口光照已是纹理，不需要再查询模型三角形。

正对相机的平面最符合这个近似；倾斜表面有投影压缩，遮挡处还可能跳到另一块表面。第 12 节将通过深度差减弱跨层混合。先在平面上解决如何用有限样本求积分，才能看清这个修正加在了哪里。

## 8. 用蒙特卡洛估算积分

我们可以遍历圆盘内每个像素来累加，但近看皮肤时，扩散范围可能覆盖几千个像素。每个出口都读取这么多次，成本很高。现在希望只读几十个位置，让每次读取代表一部分尚未读取的区域。

蒙特卡洛方法提供了这种估计方式：**按已知概率抽样，并补偿抽样频率，再求平均来估计积分。** 例如两个等面积小块，一个被抽到的次数是另一个的两倍，它每次就应代表更少的面积；否则抽得多本身就会让它贡献过大。下面从概率密度讲起，再推出这个补偿为什么是除以 pdf。

### 8.1 前提知识：从离散概率到概率密度

#### 8.1.1 随机变量

**随机变量**是"取值由随机过程决定的量"，一般用大写字母表示，如 $X$；它某一次实际取到的值用小写字母表示，如 $x$。

- **离散随机变量**：只能取有限个（或可数个）值。例如掷骰子的点数，只能是 1~6。
- **连续随机变量**：可以取某个区间里的任意实数。例如"在 $[0,1)$ 里随机取一个数"，可能是 0.3、0.31、0.3141……

本教程里的采样半径 $r$、采样角度 $\theta$ 都是连续随机变量。

#### 8.1.2 离散情况：概率与期望

离散随机变量用**概率**描述：每个取值 $x_j$ 有一个概率 $P_j$，所有概率加起来等于 1：

$$
\sum_j P_j = 1
$$

**期望** $\mathbb{E}[X]$ 是"按概率加权的平均值"，也就是大量重复实验后结果的平均：

$$
\mathbb{E}[X] = \sum_j x_j\, P_j
$$

例：普通骰子每面概率都是 $\frac16$，期望为

$$
\mathbb{E}[X] = 1\cdot\tfrac16 + 2\cdot\tfrac16 + \dots + 6\cdot\tfrac16 = 3.5
$$

如果骰子灌了铅，6 点的概率是 $\frac12$，其余五面各 $\frac1{10}$，期望变成 $(1+2+3+4+5)\cdot\frac{1}{10} + 6\cdot\frac12 = 4.5$。概率大的取值对期望的影响大，这就是"加权"的含义。

#### 8.1.3 连续情况：为什么需要"概率密度"

连续随机变量的取值有无穷多个，**取到某一个精确值的概率是 0**。比如在 $[0,1)$ 里随机取数，恰好取到 $0.5000\ldots$ 的概率为 0。所以不能像离散情况那样给每个值标一个概率。

能谈的是"落在某一**段**里的概率"。于是引入**概率密度函数**（probability density function，pdf），记作 $q(x)$：

$$
X \text{ 落在 } [x,\ x+dx] \text{ 这一小段里的概率} \approx q(x)\,dx
$$

落在区间 $[a,b]$ 里的概率，就是把这些小段的概率加起来，即积分：

$$
P(a \le X \le b) = \int_a^b q(x)\,dx
$$

**几何意义**：$q(x)$ 曲线下、$a$ 到 $b$ 之间的面积，就是落在这段里的概率。$q(x)$ 越高的地方，样本越容易落在那里。

pdf 必须满足两个条件：

1. **非负**：$q(x) \ge 0$。概率不能为负。
2. **归一化**：$\displaystyle\int q(x)\,dx = 1$。随机变量总得取某个值，所有可能性加起来是 100%。

**注意：$q(x)$ 本身不是概率，可以大于 1。** 它是"单位长度上的概率"，乘以长度 $dx$ 才是概率。例如在 $[0, 0.5]$ 上均匀取数，pdf 是 $q(x) = 2$，因为 $\int_0^{0.5} 2\,dx = 1$。

**例：均匀分布**。在 $[a,b]$ 上均匀取数，每处可能性相同，所以 $q(x)$ 是常数。由归一化 $\int_a^b c\,dx = c\,(b-a) = 1$，得到

$$
q(x) = \frac{1}{b-a}
$$

在 $[0,1)$ 上均匀分布时 $q(x) = 1$。代码里的 $u_k$、`PixelNoise` 生成的数，都可以看作这种分布。

#### 8.1.4 连续情况的期望

从离散公式出发：把 $x$ 轴切成宽度为 $\Delta x$ 的很多小段，第 $j$ 段的位置是 $x_j$，落在这段的概率约为 $q(x_j)\,\Delta x$。套用离散期望：

$$
\mathbb{E}[X] \approx \sum_j x_j\, q(x_j)\,\Delta x
$$

$\Delta x \to 0$ 时，求和变成积分：

$$
\mathbb{E}[X] = \int x\, q(x)\,dx
$$

更一般地，如果关心的不是 $X$ 本身，而是它的某个函数 $g(X)$（比如"采样点的颜色"），期望是：

$$
\boxed{\ \mathbb{E}[g(X)] = \int g(x)\, q(x)\,dx\ }
$$

含义不变：**$g$ 的取值按"$X$ 落在那里的可能性"加权平均**。这个式子是蒙特卡洛方法的基础。

#### 8.1.5 期望的线性性

期望有一个非常好用的性质：

$$
\mathbb{E}[a\,Y + b\,Z] = a\,\mathbb{E}[Y] + b\,\mathbb{E}[Z]
$$

$a, b$ 是常数，$Y, Z$ 是任意随机变量。推论：$N$ 个随机变量之和的期望，等于各自期望之和：

$$
\mathbb{E}\Big[\sum_{k} Y_k\Big] = \sum_{k} \mathbb{E}[Y_k]
$$

理由：期望本质上是积分（或求和），而积分和求和都满足"和的积分 = 积分的和""常数可以提出来"。

#### 8.1.6 独立同分布采样

**独立**：抽第 $k$ 个样本时，不受其他样本取值的影响。

**同分布**：每个样本都按同一个 pdf $q$ 抽取。

"独立同分布"（简称 i.i.d.）的 $N$ 个样本 $X_0, X_1, \dots, X_{N-1}$，就是按同一规则、互不影响地抽 $N$ 次。

#### 8.1.7 样本平均：无偏性

抽 $N$ 个样本，算 $g$ 的平均值：

$$
\bar{G}_N = \frac{1}{N}\sum_{k=0}^{N-1} g(X_k)
$$

$\bar{G}_N$ 本身也是随机的，每次重新抽样结果都不一样。它的期望是多少？用 8.1.5 的线性性：

$$
\mathbb{E}[\bar{G}_N] = \frac{1}{N}\sum_{k} \mathbb{E}[g(X_k)] = \frac{1}{N}\cdot N\cdot \mathbb{E}[g(X)] = \mathbb{E}[g(X)]
$$

中间一步用了"同分布"：每个 $X_k$ 的分布都一样，所以每个 $\mathbb{E}[g(X_k)]$ 都等于 $\mathbb{E}[g(X)]$。

**结论**：样本平均的期望**正好等于**真实期望，不管 $N$ 是多少。这叫**无偏**。意思是这个估计方法没有系统性的偏高或偏低，误差只来自随机波动。

#### 8.1.8 大数定律

无偏只说明"平均来看是对的"，单次估计仍然可能偏差很大（比如 $N=1$ 时）。**大数定律**说的是：

$$
N \to \infty \text{ 时}, \quad \bar{G}_N \to \mathbb{E}[g(X)]
$$

样本越多，样本平均越接近真实期望。掷骰子 6 次，平均值可能是 2.8；掷 10000 次，平均值会非常接近 3.5。

#### 8.1.9 方差：误差有多大、怎么减小

**方差**衡量随机变量偏离期望的程度：

$$
\mathrm{Var}[Y] = \mathbb{E}\big[(Y - \mathbb{E}[Y])^2\big]
$$

$(Y - \mathbb{E}[Y])^2$ 是"偏离期望的距离的平方"，方差就是它的平均值。方差的平方根叫**标准差**，可以粗略理解为"一次取值通常偏离期望多远"。

对 $N$ 个独立样本求平均，方差会缩小为原来的 $\frac{1}{N}$（独立随机变量之和的方差等于方差之和，再除以 $N^2$）：

$$
\mathrm{Var}[\bar{G}_N] = \frac{\mathrm{Var}[g(X)]}{N}, \qquad \text{标准差} = \frac{\sqrt{\mathrm{Var}[g(X)]}}{\sqrt{N}}
$$

这个式子在渲染里非常重要：

- 误差（标准差）按 $\frac{1}{\sqrt{N}}$ 缩小。**样本数翻 4 倍，噪点才减半**，靠堆样本数降噪代价很大。
- 另一条路是减小分子 $\mathrm{Var}[g(X)]$。这就是第 9 节**重要性采样**要做的：通过改变 $q$，让 $g$ 的取值更"平"，波动更小。
- 实时渲染中还常用 TAA（时间抗锯齿）累积不同帧的采样结果。但它需要历史重投影和随帧变化的采样图案；本地滤波只有固定的每像素旋转，没有独立实现时间累积，第 21 节再讨论如何扩展。

#### 8.1.10 多维随机变量

本教程的采样点有两个坐标 $(r,\theta)$，需要二维的 pdf $q(r,\theta)$：

$$
(r,\theta) \text{ 落在 } [r,\ r+dr]\times[\theta,\ \theta+d\theta] \text{ 这个小矩形里的概率} \approx q(r,\theta)\,dr\,d\theta
$$

归一化与期望都改成二重积分：

$$
\iint q(r,\theta)\,dr\,d\theta = 1, \qquad \mathbb{E}[g] = \iint g(r,\theta)\,q(r,\theta)\,dr\,d\theta
$$

**独立的两个变量**：如果 $r$ 和 $\theta$ 互不影响，联合 pdf 等于各自 pdf 的乘积：

$$
q(r,\theta) = q_r(r)\cdot q_\theta(\theta)
$$

这时可以**分别**抽 $r$ 和 $\theta$，再组合起来。第 10 节就是这样做的：$\theta$ 均匀抽，$r$ 按 Burley 分布抽。

**注意 pdf 是"对谁的密度"**：这里的 $q(r,\theta)$ 是对 $dr\,d\theta$ 的密度。而面积微元是 $dA = r\,dr\,d\theta$，多出来的 $r$ 不在 pdf 里，要放进被积函数（第 8.3 节的 $f$ 里有一个 $r$，就是它）。如果把 pdf 定义成对面积 $dA$ 的密度，公式会不一样。两种写法都对，但必须前后一致，不能混用。

### 8.2 蒙特卡洛估计式

#### 8.2.1 推导

目标：计算积分 $\displaystyle\int f(x)\,dx$。

**关键技巧**：选一个自己方便抽样的 pdf $q(x)$，构造新函数 $g(x) = \dfrac{f(x)}{q(x)}$。按 8.1.4 计算 $g(X)$ 的期望：

$$
\mathbb{E}\!\left[\frac{f(X)}{q(X)}\right] = \int \frac{f(x)}{q(x)}\, q(x)\, dx = \int f(x)\, dx
$$

$q$ 被约掉了，**$g(X)$ 的期望正好等于要求的积分**。积分问题就转化成了期望问题，而期望可以用样本平均来估计（8.1.7、8.1.8）：

$$
\boxed{\ \int f(x)\,dx \approx \frac{1}{N}\sum_{k=0}^{N-1} \frac{f(X_k)}{q(X_k)}, \qquad X_k \text{ 按 } q \text{ 独立抽取}\ }
$$

由 8.1.7，这个估计是无偏的；由 8.1.9，误差按 $\frac{1}{\sqrt N}$ 缩小。

**使用条件**：在 $f(x) \ne 0$ 的地方，必须有 $q(x) > 0$。否则那一段永远抽不到，它对积分的贡献就丢了，估计会偏小。

#### 8.2.2 直觉：除以 q 是在"纠正抽样的偏心"

- $q$ 大的地方样本多。如果直接平均 $f$，这些区域会被重复计算、权重偏大。所以每个样本要**除以一个大的 $q$**，降低它的"话语权"。
- $q$ 小的地方样本少，每个样本**除以一个小的 $q$**，话语权变大，代表了它周围那一大片没被抽到的区域。

最终每个区域对结果的贡献都与它在积分里的真实分量相符。

#### 8.2.3 数值例子

计算 $\displaystyle\int_0^1 x^2\,dx$，精确答案是 $\frac13 \approx 0.333$。每种方法都只用 3 个样本。

**方法 A：均匀抽样**，$q(x) = 1$，$\frac{f}{q} = x^2$。

取样本 $x = 0.2,\ 0.5,\ 0.9$：

$$
\frac{0.04 + 0.25 + 0.81}{3} \approx 0.367
$$

**方法 B：按 $q(x) = 2x$ 抽样**。$q$ 在 $x$ 大的地方更大，和 $f = x^2$ 的形状更接近。$\frac{f}{q} = \frac{x^2}{2x} = \frac{x}{2}$。

（取三个等宽区间的中点 $u=1/6,1/2,5/6$，经 $x=\sqrt u$ 得到 $x\approx0.408,0.707,0.913$。因为 $\int_0^x2t\,dt=x^2$，解 $x^2=u$ 就得到这种映射；第 10 节会用同一个办法生成 Burley 半径。这里展示一次数值估计，误差是否更小应看后面的方差，而不能靠这一组样本下结论。）

$$
\frac{0.204 + 0.354 + 0.456}{3} \approx 0.338
$$

**方法 C：按 $q(x) = 3x^2$ 抽样**。$q$ 和 $f$ 形状完全一样（只差一个常数倍）。$\frac{f}{q} = \frac{1}{3}$，**不管抽到哪里都是 $\frac13$**，一个样本就得到精确答案。

用 8.1.9 的方差比较 $g = f/q$ 的波动：

| 方法 | $q(x)$ | $g(x) = f/q$ | $\mathrm{Var}[g]$ |
|---|---|---|---|
| A | $1$ | $x^2$ | $\frac15 - \frac19 \approx 0.089$ |
| B | $2x$ | $\frac{x}{2}$ | $\frac18 - \frac19 \approx 0.014$ |
| C | $3x^2$ | $\frac13$ | $0$ |

（方差用 $\mathrm{Var}[g] = \mathbb{E}[g^2] - (\mathbb{E}[g])^2$ 计算，这是方差定义展开后的等价形式。例如方法 A：$\mathbb{E}[g^2] = \int_0^1 x^4\,dx = \frac15$，$\mathbb{E}[g] = \frac13$。）

**规律**：$q$ 的形状越接近 $f$，$f/q$ 就越接近常数，方差越小，同样样本数下噪点越少。这就是第 9 节**重要性采样**的出发点。我们的 Burley 剖面恰好能做到方法 C 那样"$q$ 与 $f$ 中的 $R(r)\,r$ 形状完全相同"。

### 8.3 套到我们的积分上

我们的被积函数（二维，变量是 $r$ 和 $\theta$）：

$$
f(r,\theta) = R(r)\, r\, I(r,\theta)
$$

在 $(r,\theta)$ 上按某个 pdf $q(r,\theta)$ 撒 $N$ 个点 $(r_k, \theta_k)$，则：

$$
L_o(p_o) \approx \rho(p_o)^{1-m}\cdot \frac{1}{N}\sum_{k} \frac{R(r_k)\, r_k}{q(r_k,\theta_k)}\, I_k
$$

$I_k$ 就是第 $k$ 个样本位置的 Diffuse RT 像素值。剩下的问题是 $q$ 怎么选。

## 9. 重要性采样：按 R(r) 的形状撒点

### 9.1 为什么不均匀撒点

假设先选一个很大的有限圆盘，在面积上均匀撒点。外圈面积很大，会得到许多样本，但那里的扩散权重已经很低；中心权重高，却只分到少量样本。若只用几十次读取，这些读取就没有用在最需要的位置。

还要分清“半径均匀”和“面积均匀”。在半径上均匀取 $r$，意味着每条等宽圆环分到相同概率；外圈面积更大，单位面积反而分到更少样本。若要在半径 $a$ 的圆盘内面积均匀，每圈概率必须正比于 $2\pi r\,dr$，因此径向密度为 $q_r(r)=2r/a^2$，由累计概率 $r^2/a^2=u$ 得到 $r=a\sqrt u$。Burley 采样又是另一种分布：让圆环概率跟着这一圈的扩散份额走。

**重要性采样**就是把更多读取分配给预期贡献大的区域，并仍用第 8 节的 $1/q$ 补偿抽样频率。

### 9.2 最理想的 q

第 4.3 节已经算过 $\int_0^{2\pi}\int_0^\infty R(r)\,r\,dr\,d\theta = 1$，也就是说 $R(r)\,r$ 本身就满足 pdf 的条件（非负、积分为 1）。直接取：

$$
q(r,\theta) = R(r)\, r = \frac{e^{-r/d} + e^{-r/(3d)}}{8\pi d}
$$

代入第 8.3 节：

$$
\frac{R(r_k)\, r_k}{q(r_k,\theta_k)} = 1 \quad\Longrightarrow\quad L_o \approx \rho^{1-m}\cdot\frac{1}{N}\sum_k I_k
$$

**单通道、平面情形下，每个样本的核权重都是 1，结果就是样本的简单平均。** 扩散形状体现在样本位置上。若 $I$ 也处处相同，估计恰好给出这个常量；若 $I$ 有阴影边缘，读到亮侧还是暗侧仍会影响结果，因此只匹配 $R(r)r$ 并不能消除全部采样误差。

### 9.3 RGB 三个 d 不一样怎么办

一次纹理读取会同时得到 RGB，因此希望三通道共用一套位置，避免各采一遍。本地实现用最宽的 $d_{max}$ 生成样本，再让通道 $c\in\{R,G,B\}$ 用自己的剖面修正贡献：

$$
w_{k,c} = \frac{R_c(r_k)\, r_k}{q_{d_{max}}(r_k,\theta_k)}
$$

- $R_c$ 用通道 $c$ 自己的 $d_c$；$q_{d_{max}}$ 用 $d_{max}$。
- 对 $d_c = d_{max}$ 的那个通道（通常是红色），$w = 1$。
- 对 $d_c$ 更小的通道（绿、蓝），远处样本的 $w$ 很小，近处样本的 $w$ 偏大。所以远处的光几乎只贡献红色，这就是颜色偏移的来源。

### 9.4 为什么除以 Σw 而不是 N

先看一个具体问题。假设有效邻居光照都是 10，而某通道有限样本的权重只有 0.2、0.3、0.3。分子是 8，除以三个样本数得到约 2.67，不能保持输入的 10；除以权重和 0.8，才得到 10。这个例子并不是说理论积分应除以任意权重和，而是说明：有限、被遮罩裁掉的核，需要重新归一化才能保持常量。

本地滤波使用：

$$
L_o\approx\rho^{1-m}\cdot\frac{\sum_k w_kI_k}{\sum_k w_k}.
$$

在没有遮罩和深度修正的平面理论中，$\mathbb E[w_c]=\int R_c(r)r\,dr\,d\theta=1$，所以分母 $\frac1N\sum w_{k,c}$ 估计的是 1。把分子和这个估计相除，两个 $1/N$ 抵消，就得到上式。这叫**自归一化估计**。有限样本下，随机分子除以随机分母通常有偏；它换来的是常量输入的稳定性，不应再沿用普通蒙特卡洛估计的无偏结论。

边缘有些样本落到非 SSS 区域时，分子和分母都不计入它们。对任意常量 $I_0$，只要分母非零：

$$
\frac{\sum_k w_k I_0}{\sum_k w_k}=I_0.
$$

因此不会仅仅因为有效样本变少，就把均匀输入压暗。三个通道分别归一化，也能避免核权重总和的差异给常量输入染色。深度修正后，这个比值对应有效邻域内重新归一化的工程核。它不保证所有像素之间交换的能量全局守恒：出口不同、参数不同、遮挡不同，使用的归一化核也不同。

## 10. 怎么生成服从 Burley 分布的半径 r

现在知道样本应该按哪条曲线分布，还需要把它变成能执行的代码。GPU 很容易生成 $[0,1)$ 中的数，但我们需要毫米单位的半径：例如累计份额到达 50% 的位置，应该对应 $u=0.5$。这一节通过“累计份额 → 反求半径”建立映射，最后得到本地 `SampleBurley` 的计算步骤。

### 10.1 拆分 r 和 θ

$q(r,\theta) = R(r)\,r$ 和 $\theta$ 无关，所以可以拆成两个独立的部分：

- $\theta$：在 $[0, 2\pi)$ 上均匀分布，密度 $\frac{1}{2\pi}$。
- $r$：密度 $q_r(r) = 2\pi\, R(r)\, r = \frac{e^{-r/d} + e^{-r/(3d)}}{4d}$。

两者相乘正好等于 $q(r,\theta)$。角度好办（第 11 节），难的是 $r$。

### 10.2 前提知识：逆变换采样

**累积分布函数（CDF）**：$C(r) = \int_0^r q_r(t)\, dt$，表示"半径小于 $r$ 的概率"。它从 0 单调增到 1。

**逆变换采样**：取 $[0,1)$ 上的均匀数 $u$，解方程 $C(r) = u$ 得到 $r = C^{-1}(u)$，这样得到的 $r$ 就服从 $q_r$。

为什么成立：

$$
P(r \le x) = P\big(C^{-1}(u) \le x\big) = P\big(u \le C(x)\big) = C(x)
$$

最后一步是因为 $u$ 均匀分布，$u \le$ 某个值的概率就等于那个值。$r$ 的 CDF 正是 $C$，所以分布对了。

直观理解：$C(r)$ 陡的地方（pdf 大的地方），$u$ 的一大段区间都会映射到很小的一段 $r$ 上，样本自然就密集了。

### 10.3 求 CDF

$$
C(r) = \int_0^r \frac{e^{-t/d} + e^{-t/(3d)}}{4d}\, dt
= \frac{1}{4d}\Big[d\,(1-e^{-r/d}) + 3d\,(1 - e^{-r/(3d)})\Big]
$$

$$
C(r) = 1 - \frac{1}{4}e^{-r/d} - \frac{3}{4}e^{-r/(3d)}
$$

### 10.4 解方程 C(r) = u

令 $\tau = r/d$，$y = e^{-\tau/3}$（所以 $e^{-\tau} = y^3$），再令 $v = 1 - u$：

$$
1 - \tfrac14 y^3 - \tfrac34 y = u \quad\Longrightarrow\quad y^3 + 3y = 4v
$$

这是一个三次方程。不用记卡尔达诺公式，用"猜形式 + 验证"就能解：

**猜** $y = a - \frac{1}{a}$。展开立方：

$$
y^3 = a^3 - 3a + \frac{3}{a} - \frac{1}{a^3} = \left(a^3 - \frac{1}{a^3}\right) - 3\left(a - \frac{1}{a}\right) = \left(a^3 - \frac{1}{a^3}\right) - 3y
$$

所以 $y^3 + 3y = a^3 - \frac{1}{a^3}$。令 $A = a^3$，方程变成：

$$
A - \frac{1}{A} = 4v \quad\Longrightarrow\quad A^2 - 4vA - 1 = 0 \quad\Longrightarrow\quad A = 2v + \sqrt{4v^2 + 1}
$$

（取正根，因为 $a > 0$。）于是：

$$
y = A^{1/3} - A^{-1/3}, \qquad r = -3d\,\ln y
$$

### 10.5 避免相近数相减的等价改写

当 $u$ 靠近 1，样本进入长尾，$v=1-u$ 很小。此时 $A^{1/3}$ 和 $A^{-1/3}$ 都接近 1，相减会损失精度。本地代码采用下面没有这次相减的形式。

利用 $(a - \frac1a)(1 + a^2 + \frac{1}{a^2}) = a^3 - \frac{1}{a^3} = 4v$（展开即可验证），得到：

$$
y = \frac{4v}{1 + a^2 + a^{-2}}
$$

再令 $g = A^2$，则 $a^2 = g^{1/3}$、$a^{-2} = g^{-1/3}$，并且：

$$
g = (2v + \sqrt{4v^2+1})^2 = 1 + 4v\left(2v + \sqrt{1 + 4v^2}\right)
$$

这就是代码：

```hlsl
float v = 1.0 - u;
float g = 1.0 + 4.0 * v * (2.0 * v + sqrt(1.0 + 4.0 * v * v));
float n = pow(g, -1.0 / 3.0);   // g^(-1/3) = a^(-2)
float p = g * n * n;            // g^(+1/3) = a^2
float c = 1.0 + p + n;
float y = 4.0 * v / c;          // y = exp(-r / 3d)
r = -3.0 * log(y) * d;
```

### 10.6 顺便算出 1/q

第 9.3 节的权重要除以 $q$。$q$ 也能用 $y$ 表示：

$$
q(r,\theta) = \frac{e^{-\tau} + e^{-\tau/3}}{8\pi d} = \frac{y^3 + y}{8\pi d}
\quad\Longrightarrow\quad
\frac{1}{q} = \frac{8\pi d}{y^3 + y}
$$

```hlsl
rcpPdf = 8.0 * PI * d / (y * y * y + y);
```

这里返回的是联合密度 $q(r,\theta)$ 的倒数，包含角度的 $2\pi$，不是径向密度 $q_r$ 的倒数。采样函数里的 `d` 是标量，调用时传入 $d_{max}$；计算 RGB 核时才使用向量 $(d_R,d_G,d_B)$。若改看以 ShapeParam 表示的实现，应先用 $s=1/d$ 对照：指数 $-r/d=-rs$，前面的 $1/d=s$，不能只改变量名。

最后检查端点：$u=0$ 对应 $r=0$，$u\to1$ 对应 $r\to\infty$。不能把 $u=1$ 送入代码，否则 $y=0$，`log(y)` 无法给出有限半径。下一节的区间中点恰好避开两端。

## 11. 角度、截断半径与采样数

### 11.1 把累计概率分层

逆 CDF 已能把任意 $u$ 映成半径。若预算只有 4 个样本，完全随机的 4 个 $u$ 可能都落在前半区，远处光照一次也没读到。本地取 $u_k=(k+0.5)/N$：当 $N=4$ 时，得到 0.125、0.375、0.625、0.875，每一份等概率区间都有一个代表。

这是分层的确定性中点取样。每层在 CDF 上等宽，映到半径上却不等宽：近处 pdf 大，半径间隔小；尾部 pdf 小，半径间隔大。本地再配合黄金角组成圆盘图案，因此第 8 节独立随机样本的无偏性和方差公式用于理解方法，不是这套有限确定性图案的严格误差保证。

### 11.2 给每个半径一个方向

半径确定后，还要决定沿哪个方向读取。若每次只转 90°，样本总在四条射线上，容易漏掉射线之间的光照。本地每次转黄金角约 2.39996 弧度，即：

$$
\theta_k=\text{phase}+k\,2.39996323.
$$

黄金角为 $2\pi(1-1/\varphi)$，$\varphi=(1+\sqrt5)/2$。它避免短周期重复方向，使有限样本较均匀地铺开；不意味着任意样本数都严格角度均匀。

`phase` 来自像素坐标的伪随机数，取值在 $[0,2\pi)$。它把整套图案旋转，减少所有像素共用同一方向造成的条纹。本地 `PixelNoise` 不含帧号，所以固定像素的相位不随帧改变；时间降噪还需要第 21 节的配合。

### 11.3 16.56d：用来估计范围，不是采样硬截断

长尾没有有限终点，但估计屏幕覆盖面积时需要一个代表性半径。取累计份额 99.7%，解 $C(r)=0.997$。此时 $v=0.003$，代入第 10 节：

$$
y\approx0.004,\qquad r/d=-3\ln y\approx16.56.
$$

于是定义估计半径 $r_{\mathrm{est}}=16.56d_{max}$。它用于下一节预算样本数。本地循环仍把 $(k+0.5)/N$ 直接送入完整逆 CDF，没有乘 0.997，也没有拒绝超过 $r_{\mathrm{est}}$ 的样本。

实际最外样本由 $u_{max}=1-0.5/N$ 决定。例如 $N=32$ 时 $u_{max}=0.984375$，其半径约为 $11.61d_{max}$，小于估计半径。若另行实现 99.7% 硬截断，就需要改为对截断分布采样，并使用相应的条件 pdf；那不是当前循环的行为。

### 11.4 根据屏幕面积分配读取预算

同样 5 mm 的散射，近看可能跨很多像素，远看却不到一个像素。因此先把估计半径换成像素 $R_{px}$，再计算：

$$
R_{px}=16.56d_{max}\,\text{pixelsPerMm},\qquad
N=\min\left(\left\lfloor\frac{\pi R_{px}^2}{4}\right\rfloor,\ \text{budget}\right).
$$

$\pi R_{px}^2$ 是估计圆盘的像素面积，除以 4 表示约每 4 个像素分配一次读取；向下取整对应代码的 `uint` 转换。预算是上限，不是每个像素固定执行的次数。

若 $N<1$，直接保留中心输入，避免为很小的屏幕范围启动循环。这个分支由“估计面积除以 4 后不足 1”触发，不能精确解释成实际散射半径小于一个像素。即使 $N$ 较大，偏移取整后也可能多次读到同一个像素。下一节将推导毫米怎样换成像素。

## 12. 屏幕空间的补丁：单位换算与双边权重

### 12.1 从透视投影得到毫米与像素的关系

采样函数给出“向旁边走 2 mm”，纹理却需要“向旁边走几个像素”。同样的毫米偏移，距离相机越远，屏幕位移越小，因此要用当前中心深度计算比例。

令 $z>0$ 为视空间沿相机前向的线性深度，$x$ 为横向位置。标准透视投影满足 $x_{ndc}=P_{00}x/z$；NDC 横向从 $-1$ 到 $1$，总宽度是 2。RT 宽度为 $W$ 时，一个像素对应 $\Delta x_{ndc}=2/W$。在中心深度固定的小平面上反解：

$$
\Delta x=\frac{z}{P_{00}}\Delta x_{ndc}
=\frac{2z}{P_{00}W}.
$$

假设 1 Unity 单位等于 1 米，就得到：

$$
\text{metersPerPixel}=z\frac{2}{P_{00}W},\qquad
\text{pixelsPerMm}=\frac{1}{1000\,\text{metersPerPixel}}.
$$

例如一个像素宽 2 mm，则每毫米是 0.5 像素，4 mm 偏移应移动 2 像素。最终二维偏移为：

$$
\Delta\mathbf p_{px}=r_k\,\text{pixelsPerMm}
(\cos\theta_k,\sin\theta_k).
$$

C# 每帧传入 $2/(P_{00}W)$，Shader 再乘中心的线性深度。`LinearEyeDepth` 得到的是视轴深度，不是相机到点的欧氏距离。普通透视投影与方形像素下，纵向用 $P_{11}$ 和高度也应得到相同尺度；正交投影则不应再乘 $z$，当前代码没有单独处理该分支。模型单位不等于米时，也要一并改毫米换算，而不是只调宽散射距离掩盖比例问题。

### 12.2 深度差如何减少跨表面混合

鼻尖与后方脸颊在屏幕上可能只差几个像素。只看二维偏移，会把两者当作紧邻入口。现在读取样本深度，与中心相减并换成毫米：

$$
\Delta z_k=1000(z_k-z_o),\qquad
r'_k=\sqrt{r_k^2+\Delta z_k^2}.
$$

例如横向 2 mm、深度差 20 mm，修正距离约为 20.1 mm。把这个较大的距离送入衰减函数，就能压低跨深度层的贡献。

为看清本地实现，先把第 9 节反复出现的乘积命名为 $K_c(t)$：

$$
K_c(t)=R_c(t)t
=\frac{e^{-t/d_c}+e^{-t/(3d_c)}}{8\pi d_c}.
$$

代码 `BurleyTimesR` 计算的正是 $K$，它在 $t=0$ 也有有限极限。深度修正后，本地权重写成：

$$
w_{k,c}=\frac{K_c(r'_k)}{q_{d_{max}}(r_k,\theta_k)}.
$$

分子使用修正距离，分母保留原始撒点的 pdf：样本仍由屏幕平面半径 $r_k$ 生成，不能因为读取深度后得到 $r'_k$，就假装它原来按另一个分布抽取。

这里把整个 $R(t)t$ 函数在 $t=r'$ 处求值，是本地的双边权重近似。若只在原平面积分中把剖面距离替换为 $r'$，面积因子仍会是 $r\,dr\,d\theta$，分子应为 $R(r')r$；若真要积实际曲面，还需要投影到曲面面积的 Jacobian。当前实现没有求这些面积变换，也没有完整重建三维两点距离。因此它能抑制深度不连续处的混合，但不是严格曲面面积积分。

当 $\Delta z=0$ 时，$K(r')=R(r)r$，回到平面推导。深度差增大时权重连续衰减；代码没有“深度超过阈值立即丢弃”的分支。

### 12.3 哪些邻居允许参与

参数 RT 的 alpha 表示是否画出了 SSS 表面。alpha 为 0 的邻居直接跳过，剩下的按第 9.4 节重新归一化。这样不会直接把清屏背景的黑色混入皮肤。

但本地深度 RT 只画 SSS 物体，没有普通不透明遮挡物的深度；mask 也只有是否为 SSS 的一位信息，没有对象 ID。两块不同物体只要都是 SSS、深度又接近，仍可能互相混合。屏幕边界处代码采用 `clamp`，超界样本会反复读取边界像素，而不是获得屏幕外真实光照。理解这些数据范围，才能区分滤波算法的问题与屏幕根本没有提供的信息。

## 13. 最终工程公式

现在按一次像素计算把各节接起来：先从中心参数得到 RGB 散射距离与样本预算；按最宽通道生成位置；读取邻居光照、mask 和深度；计算 RGB 权重并累加；最后归一化，乘回出口颜色，加回表面高光。对于 $m=0.5$，写成：

$$
\boxed{\;
L_{final}(p_o) = \sqrt{\rho(p_o)}\cdot\frac{\displaystyle\sum_{k\in\text{有效}} w_k\, I_k}{\displaystyle\sum_{k\in\text{有效}} w_k} \;+\; L_{spec}(p_o)
\;}
$$

其中：

| 量 | 计算方式 | 来自 |
|---|---|---|
| $I_k$ | Diffuse RT 在样本像素的值 $= \sqrt{\rho}\cdot D$ | 第 5、6 节 |
| $u_k$ | $\frac{k+0.5}{N}$ | 第 11.1 节 |
| $r_k$ | 用 $u_k$、$d_{max}$ 解逆 CDF | 第 10 节 |
| $\theta_k$ | $\text{phase} + k \times 2.39996$ | 第 11.2 节 |
| 样本像素 | 中心像素 $+ r_k\cdot\text{pixelsPerMm}\cdot(\cos\theta_k,\sin\theta_k)$ | 第 12.1 节 |
| $r'_k$ | $\sqrt{r_k^2 + \Delta z_k^2}$ | 第 12.2 节 |
| $w_{k,c}$ | $\dfrac{e^{-r'_k/d_c} + e^{-r'_k/(3d_c)}}{8\pi d_c}\cdot\dfrac{8\pi d_{max}}{y_k^3 + y_k}$ | 第 9.3、10.6、12.2 节 |
| 有效 | 样本在 SSS 物体上（遮罩 > 0） | 第 12.3 节 |
| $N$ | $\min(\lfloor\pi R_{px}^2/4\rfloor,\ \text{budget})$，$R_{px}=16.56d_{max}\cdot\text{pixelsPerMm}$ 仅用于预算 | 第 11.3、11.4 节 |
| $L_{spec}$ | 普通的 PBR 高光 + 环境反射 | 第 3 节 |

表中 $y_k=\exp[-r_k/(3d_{max})]$，由逆 CDF 函数同时得到；$d_c$ 来自中心像素。分子、分母以及最后的除法全部逐 RGB 通道计算。若某通道总权重太小，代码返回该通道的中心输入；若 $N=0$，整次滤波直接返回中心输入。这时前后两份平方根颜色相乘，恢复未散射的 $\rho D$。

这套公式最适合可见、局部较平、参数缓慢变化的厚表面。深度权重减少跨层混合，却补不回被遮挡入口的光；有限样本会在明暗变化处留下误差；薄耳朵的背光透射还需要另一条光照路径。接下来看 HDRP 的职责划分，再把同样的职责落实到本地三个源码文件。

## 14. Unity HDRP 实际是怎么做的

### 14.1 先看共享的职责划分

参考 HDRP 的价值，是理解 SSS 为什么需要独立的光照数据，而不是把一段 Compute Shader 原样搬入 URP。阅读 HDRP 的 Burley 路径时，可以沿着这条线索寻找数据：

1. **标记材质与扩散参数。** 像素需要知道自己是否参与 SSS，以及使用哪个 Diffusion Profile；profile 集中存放散射尺度等参数。
2. **拆分光照（split lighting）。** 漫反射保留为可以被散射处理的缓冲，高光走表面反射路径。颜色放在滤波前后的方式由 Texturing Mode 决定。
3. **空间散射。** 在 `SubsurfaceScattering.compute` 相关路径中，用扩散剖面、采样分布和深度信息混合邻居，再将结果合成。
4. **处理独立需求。** 时间抗锯齿负责利用历史信息降低采样误差；Transmission 负责薄表面背面的入射贡献。它们不是增大屏幕模糊半径的别名。

不同 HDRP 版本的 buffer 布局、线程组织、预算选项和合成方式会变化。这里用它说明架构与数学思路；本文逐行教学对应的是本地 URP 三份源码，不把线程组大小、profile 数量或宏开关当作跨版本约定。

### 14.2 读参数时先统一单位

| 参数概念 | 用途 | 本地对应 |
|---|---|---|
| Scattering Distance | 控制 RGB 扩散范围 | `_ScatterColor.rgb * _ScatterDistance`，直接作为毫米尺度 $d$ |
| ShapeParam | 用倒数形式保存形状 | $s=1/d$；本地直接用 $d$，不要把 $s$ 原值写进参数 RT |
| World Scale | 世界单位与物理长度换算 | 本地固定 1 Unity 单位为 1 米 |
| Texturing Mode | 决定颜色参与滤波的阶段 | 本地固定 $m=0.5$，前后各乘平方根 |
| Thickness / Transmission | 描述薄部位的透射 | 本地尚未实现 |

例如参考代码若计算 `exp(-r * s)`，本地应对照 `exp(-r / d)`。面板显示的距离、内部缓存参数以及可能的重映射，也要按所用 HDRP 版本确认后再移植。

### 14.3 本地实现保留了什么、简化了什么

本地保留了可复用的主线：拆出漫反射、使用 Burley 形状、按最宽通道生成圆盘样本、逐通道加权并归一化。为了展示这条主线，它采用每像素直接存 $d$、全屏 Pixel Shader、alpha 遮罩和主光源加 SH 环境光，没有建立完整的 profile 管理、额外光源与时间累积系统。

因此，后面的重点是四张 RT 如何传递这些量，以及每段代码如何完成第 13 节的一步。它是一套独立的 Burley 管线：`SSSBurleyFeature` 调度 `SSSBurleyLit` 与 `SSSBurleyFilter`，不能与 `SSSLit` 或可分离滤波管线的 Pass 名、RT 内容和合成时机混搭。

# 第二部分：实践——在 URP 里写出来

## 15. 整体数据流

### 15.1 用到的 RT

想象最终前向 Pass 正在画脸颊像素 B：它需要已经混合好的邻居光照，但此时若才开始询问邻居，邻居还未必完成着色。因此要先画一次 SSS 材质，把输入存下来，再全屏滤波，最后让正常前向绘制读取结果。四张 RT 就是这些阶段之间的数据接口。

下文代码块按职责节选；带 `...` 的块是结构示意，完整声明、include 和资源释放见配套源码。

| RT | 内容 | 格式 | 写入者 | 读取者 |
|---|---|---|---|---|
| `_SSSDiffuseRT` | $I = \sqrt{\rho}\cdot D$ | ARGBHalf | 步骤一 | 步骤三 |
| `_SSSParamRT` | rgb = $d$（毫米），a = 遮罩 | ARGBHalf | 步骤一 | 步骤三 |
| `_SSSDepthRT` | 仅参与预绘制的 SSS 物体深度 | `D32_SFloat_S8_UInt` | 步骤一 | 步骤三 |
| `_SSSResultRT` | $\sum wI / \sum w$ | ARGBHalf | 步骤三 | 步骤四 |

> **为什么 Diffuse 用 Half 格式**：光照值会超过 1（强光、HDR），8 位格式会截断并产生色带。

> **为什么要有自己的深度 RT**：
> 1. 步骤一画 SSS 物体时需要深度测试，否则物体背面会盖住正面。
> 2. 步骤三需要深度算 $\Delta z$。
> 3. 独立深度附件让 MRT 预绘制与后续读取采用一致的单采样尺寸。相机是否已有完整深度取决于 URP 配置，不能只凭执行事件假定它可直接复用；这里也没有把普通遮挡物复制进这张深度图。

### 15.2 执行顺序

```
URP 一帧:
  阴影 → 深度预渲染 → [SSSBurleyPass: 步骤一 + 步骤三] → 不透明物体（含步骤四） → 天空盒 → ...
                        ↑ RenderPassEvent.AfterRenderingPrePasses
```

SSS 必须在不透明物体**之前**算好，因为步骤四（SSS 材质的前向 Pass）要读结果。

## 16. 步骤一：材质 Shader 输出漫反射与参数

文件：`Assets/SSS-TEST/SSSBurley/SSSBurleyLit.shader`，Pass `SSSBurleyDiffuse`。

### 16.1 目的

对应理论第 5、6 节：每个 SSS 像素算出 $I=\sqrt{\rho}D$，同时存下散射参数 $d$ 和遮罩，并写深度。比如同一盏灯照到两个颜色不同的像素，它们的 $D$ 可以相同，但 $I$ 因平方根颜色不同而不同；相同颜色、不同散射距离的像素，则可能写出相同的 $I$、不同的参数 RT。把两张图分开，才能独立控制“输入多亮”和“混合多宽”。

### 16.2 自定义 LightMode：让这个 Pass 只被我们的 Feature 画

```hlsl
Pass
{
    Name "SSSBurleyDiffuse"
    Tags { "LightMode" = "SSSBurleyDiffuse" }
    ZWrite On
    ZTest LEqual
    Cull Back
    ...
}
```

- URP 只会自动画 `LightMode` 为 `UniversalForward`、`ShadowCaster`、`DepthOnly` 等内置名字的 Pass。
- 写一个自定义名字 `SSSBurleyDiffuse`，URP 就不会自己画它。我们在 C# 里用 `new ShaderTagId("SSSBurleyDiffuse")` 告诉 `DrawRenderers`"只画带这个标签的 Pass"，就能把所有 SSS 物体画到我们自己的 RT 上。
- 没有这个 Pass 的物体（地面、墙）不会被画，Diffuse RT 上对应位置保持清屏的 0，遮罩也是 0。

### 16.3 MRT：一次输出两张图

```hlsl
struct FragOutput
{
    half4 diffuse : SV_Target0; // rgb = D * sqrt(albedo)
    half4 param   : SV_Target1; // rgb = 每通道散射距离 d（毫米），a = SSS 遮罩
};
```

MRT（Multiple Render Targets）：片元着色器同时往多张 RT 写数据。`SV_Target0` 写到 C# 里绑定的第 0 张，`SV_Target1` 写到第 1 张。这样只画一遍物体就得到两张图，比画两遍省。

### 16.4 计算 D

```hlsl
// 皮肤折射率约 1.4 → F0 = ((1.4-1)/(1.4+1))^2 ≈ 0.028
#define SKIN_F0 0.028

float FresnelSchlick(float f0, float cosTheta)
{
    return f0 + (1.0 - f0) * pow(1.0 - saturate(cosTheta), 5.0);
}

FragOutput frag(Varyings i)
{
    half3 albedo = SampleAlbedo(i.uv);
    float3 n = normalize(i.normalWS);
    float3 v = normalize(GetCameraPositionWS() - i.positionWS);

    Light light = GetMainLight(TransformWorldToShadowCoord(i.positionWS));
    float3 h = normalize(v + light.direction);
    float NdotL = saturate(dot(n, light.direction));

    // 进入皮肤的比例 = 1 - 表面反射掉的比例
    float kdDirect  = 1.0 - FresnelSchlick(SKIN_F0, dot(v, h));
    float kdAmbient = 1.0 - FresnelSchlick(SKIN_F0, dot(n, v));

    // D：一个"白色"漫反射表面在这里接收到的光（不含 albedo）
    float3 D = kdDirect * light.color * (light.shadowAttenuation * light.distanceAttenuation * NdotL)
             + kdAmbient * SampleSH(n);

    FragOutput o;
    o.diffuse = half4(D * sqrt(albedo), 1);
    o.param = half4(_ScatterColor.rgb * _ScatterDistance, 1);
    return o;
}
```

逐行对应理论：

| 代码 | 理论 |
|---|---|
| `FresnelSchlick` | 菲涅尔反射率 $F$ 的 Schlick 近似：$F = F_0 + (1-F_0)(1-\cos)^5$。$F_0$ 是垂直入射时的反射率，由折射率 $\eta$ 决定：$F_0 = \left(\frac{\eta-1}{\eta+1}\right)^2$ |
| `kdDirect = 1 - F` | 直接光用 $V\cdot H$、环境光用 $N\cdot V$ 估计反射扣除。这是着色近似，不是严格按入口 $N\cdot L$ 求出的边界透射积分；因此代码中的 $D$ 仍随视角变化 |
| `light.color * shadow * NdotL` | 第 5 节内层积分的主光源部分。阴影一定要乘在这里，SSS 最明显的效果就是阴影边缘发红 |
| `SampleSH(n)` | 环境光（球谐） |
| `D * sqrt(albedo)` | 第 6 节，$m = 0.5$ 的模糊前那一半 |
| `_ScatterColor.rgb * _ScatterDistance` | $d_R, d_G, d_B$（毫米）。颜色决定三通道的比例，距离决定整体大小 |
| `param.a = 1` | 遮罩：这里是 SSS 物体 |

**参数设计**：材质默认 `_ScatterColor=(1,0.35,0.2)`、`_ScatterDistance=5`，得到 $d=(5,1.75,1)$ mm。红通道最宽，所以同一套样本的远处输入主要影响红色。这个参数是扩散形状尺度，不是介质厚度，也不是所有光最多传播的距离；先确认模型的真实尺寸，再调节它。

这里的法线来自模型顶点插值，代码没有法线贴图采样，也没有附加光源循环。`sqrt(albedo)` 应在非负线性颜色上执行：颜色贴图由正确的 sRGB 导入设置解码，散射距离则是数值参数，不要把参数 RT 当作颜色图做色彩空间转换。

## 17. 步骤二：Renderer Feature 组织流程

文件：`Assets/SSS-TEST/SSSBurley/SSSBurleyFeature.cs`

### 17.1 前提知识：URP 的 Renderer Feature

材质知道怎样输出 $I$ 和 $d$，却不知道该画进哪张图、何时滤波。Renderer Feature 负责调度，Shader 负责每个像素的计算。先分清这两层，下面的命令顺序就有了目的：先建立输入，再消费输入，最后发布结果。

- **`ScriptableRendererFeature`**：挂在 Renderer 资源上的插件。`Create()` 创建运行时资源，编辑器重建或配置变化时也可能再次调用，不应理解为整个运行期间只调用一次。`AddRenderPasses()` 为当前相机加入需要的 Pass。
- **`ScriptableRenderPass`**：真正干活的类。`renderPassEvent` 决定它插在哪个位置；`OnCameraSetup()` 在执行前调用，适合分配 RT；`Execute()` 里录制渲染命令。
- **`CommandBuffer`**：命令列表。往里添加"设置 RT""画东西"等命令，`context.ExecuteCommandBuffer(cmd)` 时才提交。
- **`RTHandle`**：URP 14 的 RT 包装类，配合 `RenderingUtils.ReAllocateIfNeeded` 使用：尺寸或格式变了才重新分配，否则复用。

### 17.2 选择执行时机

```csharp
renderPassEvent = RenderPassEvent.AfterRenderingPrePasses;
```

- 必须在**阴影之后**：步骤一要采样阴影图。
- 必须在**不透明物体之前**：步骤四要读结果。
- 本地选择预通道之后执行，使绘制发生在正常相机设置之后，同时赶在不透明前向合成之前。若把 Pass 移到更早的阴影阶段附近，需要重新确认相机矩阵、光照常量和附件状态，不能只修改事件枚举就假定其余条件不变。

### 17.3 分配 RT

```csharp
public override void OnCameraSetup(CommandBuffer cmd, ref RenderingData renderingData)
{
    var desc = renderingData.cameraData.cameraTargetDescriptor;
    desc.msaaSamples = 1;
    desc.depthBufferBits = 0;
    desc.colorFormat = RenderTextureFormat.ARGBHalf;
    RenderingUtils.ReAllocateIfNeeded(ref m_DiffuseRT, desc, FilterMode.Point, TextureWrapMode.Clamp, name: "_SSSDiffuseRT");
    RenderingUtils.ReAllocateIfNeeded(ref m_ParamRT, desc, FilterMode.Point, TextureWrapMode.Clamp, name: "_SSSParamRT");
    RenderingUtils.ReAllocateIfNeeded(ref m_ResultRT, desc, FilterMode.Point, TextureWrapMode.Clamp, name: "_SSSResultRT");

    var depthDesc = desc;
    depthDesc.graphicsFormat = GraphicsFormat.None;
    depthDesc.depthStencilFormat = GraphicsFormat.D32_SFloat_S8_UInt;
    RenderingUtils.ReAllocateIfNeeded(ref m_DepthRT, depthDesc, FilterMode.Point, TextureWrapMode.Clamp, name: "_SSSDepthRT");
}
```

- 以相机目标的描述符为模板，尺寸自动和相机一致（包括 Render Scale）。
- `msaaSamples = 1`：当前 Shader 使用普通 `TEXTURE2D` 和整数像素 `LOAD`，因此附件采用单采样。多采样纹理需要专门的读取或 resolve 路径，不能直接套用这段代码。
- 颜色 RT 不需要自带深度（`depthBufferBits = 0`），深度单独一张。
- 深度 RT：`graphicsFormat = None` 表示没有颜色部分，`depthStencilFormat` 指定深度格式。这种纯深度 RT 也可以在 shader 里当纹理读（读出来的 `.r` 就是深度值）。
- `FilterMode.Point`：滤波 shader 用 `LOAD_TEXTURE2D` 按整数像素读取，不需要插值。

### 17.4 Execute 第 1 段：画 SSS 物体

```csharp
cmd.SetRenderTarget(new RenderTargetIdentifier[] { m_DiffuseRT, m_ParamRT }, m_DepthRT);
cmd.ClearRenderTarget(true, true, Color.clear);
context.ExecuteCommandBuffer(cmd);
cmd.Clear();

var drawing = CreateDrawingSettings(k_DiffuseTag, ref renderingData, SortingCriteria.CommonOpaque);
context.DrawRenderers(renderingData.cullResults, ref drawing, ref m_Filtering);
```

- `SetRenderTarget(颜色数组, 深度)`：绑定 MRT。数组第 0 个对应 shader 里的 `SV_Target0`，第 1 个对应 `SV_Target1`。
- `ClearRenderTarget(true, true, Color.clear)`：深度清成最远，颜色清成 0。清成 0 很关键，遮罩 alpha = 0 表示"不是 SSS 物体"。
- **必须先 `ExecuteCommandBuffer` 再 `DrawRenderers`**：`DrawRenderers` 是直接提交给 context 的，不在 cmd 里。如果不先提交 cmd，设置 RT 的命令会排在画物体之后执行，物体就画错地方了。
- `CreateDrawingSettings(k_DiffuseTag, ...)`：只画带 `LightMode = SSSBurleyDiffuse` 的 Pass。它会继承相机的灯光、阴影等每物体数据。
- `m_Filtering = new FilteringSettings(RenderQueueRange.opaque)`：只考虑不透明队列的物体。
- `renderingData.cullResults`：URP 已经做好的视锥剔除结果，复用即可。

### 17.5 Execute 第 2 段：滤波

```csharp
var desc = renderingData.cameraData.cameraTargetDescriptor;
var proj = renderingData.cameraData.GetProjectionMatrix();
cmd.SetGlobalTexture(k_ParamRT, m_ParamRT);
cmd.SetGlobalTexture(k_DepthRT, m_DepthRT);
cmd.SetGlobalVector(k_Params, new Vector4(
    2f / (proj.m00 * desc.width),
    m_Settings.sampleBudget,
    desc.width,
    desc.height));
Blitter.BlitCameraTexture(cmd, m_DiffuseRT, m_ResultRT, m_Material, 0);
```

- `SetGlobalTexture / SetGlobalVector`：设成全局变量，所有 shader 里同名变量都能读到。
- `_SSSParams.x = 2/(P00·width)`：第 12.1 节的系数，乘以深度就是每像素对应的米数。
- `_SSSParams.zw`：RT 尺寸，用来防止采样越界。
- `Blitter.BlitCameraTexture(cmd, 源, 目标, 材质, pass)`：画一个铺满目标的全屏三角形，用指定材质的指定 Pass，并把"源"自动绑定到 shader 的 `_BlitTexture`。这就是步骤三的入口。

### 17.6 Execute 第 3、4 段：传出结果、还原渲染目标

```csharp
cmd.SetGlobalTexture(k_ResultRT, m_ResultRT);

var renderer = renderingData.cameraData.renderer;
CoreUtils.SetRenderTarget(cmd, renderer.cameraColorTargetHandle, renderer.cameraDepthTargetHandle);

context.ExecuteCommandBuffer(cmd);
CommandBufferPool.Release(cmd);
```

- `_SSSResultRT` 设成全局纹理，步骤四的前向 Pass 才能读到。
- **还原渲染目标**：URP 会记住"当前绑定的是哪个 RT"，如果下一个 Pass 的目标和它记住的一样，就不会重新绑定。我们在 cmd 里偷偷换了 RT，URP 并不知道，下一个 Pass（画不透明物体）可能就画到我们的 RT 上去了。所以结束前手动绑回相机的颜色和深度。

### 17.7 Feature 主体

```csharp
public override void Create()
{
    if (settings.filterShader == null) return;
    m_Material = CoreUtils.CreateEngineMaterial(settings.filterShader);
    m_Pass = new SSSBurleyPass(settings, m_Material);
}

public override void AddRenderPasses(ScriptableRenderer renderer, ref RenderingData renderingData)
{
    var cameraType = renderingData.cameraData.cameraType;
    if (m_Pass == null || (cameraType != CameraType.Game && cameraType != CameraType.SceneView))
        return;
    renderer.EnqueuePass(m_Pass);
}
```

- `CreateEngineMaterial`：用 shader 创建一个不保存到磁盘的材质（隐藏标记），`Dispose` 时用 `CoreUtils.Destroy` 销毁。
- 只对 Game 和 Scene 视图相机入队。材质预览、反射探针等相机不会获得这一套结果。由于材质前向 Pass 无条件读取全局结果纹理，跳过相机并不自动产生普通 Lit 回退；支持更多相机时需要同时设计结果生命周期与回退着色。

源码的 `Dispose(bool)` 调用 Pass 的 `Dispose()` 释放四个 RTHandle，再销毁运行时材质。理解资源生命周期同样重要：画面每帧更新不代表每帧创建纹理，退出或重建资源时则不能只留下全局纹理名而不释放底层对象。

## 18. 步骤三：散射滤波 Shader

文件：`Assets/SSS-TEST/SSSBurley/SSSBurleyFilter.shader`

### 18.1 目的

对每个 SSS 像素执行第 13 节的加权平均，输出 $\sum wI/\sum w$。阅读时把函数分成四段：读取中心并决定是否需要滤波；把毫米换成像素并决定读取次数；循环读取邻居；归一化输出。输出还没有乘出口的平方根颜色，所以不能直接拿它当最终皮肤颜色。

### 18.2 全屏三角形顶点着色器

```hlsl
struct Attributes { uint vertexID : SV_VertexID; };
struct Varyings   { float4 positionCS : SV_POSITION; };

Varyings vert(Attributes v)
{
    Varyings o;
    o.positionCS = GetFullScreenTriangleVertexPosition(v.vertexID);
    return o;
}
```

`Blitter` 画的是一个只有 3 个顶点、没有顶点缓冲的大三角形，它盖住整个屏幕。`SV_VertexID` 是顶点编号 0、1、2，`GetFullScreenTriangleVertexPosition` 根据编号算出三角形顶点位置。这样屏幕上每个像素都会执行一次片元着色器。

### 18.3 用 LOAD 按像素读取

```hlsl
int2 pixel = int2(i.positionCS.xy);
float3 centerIrradiance = LOAD_TEXTURE2D(_BlitTexture, pixel).rgb;
```

- 片元着色器里的 `SV_POSITION.xy` 是当前像素的屏幕坐标（像素中心，如 `(100.5, 200.5)`），转成 `int2` 就是像素编号。
- `LOAD_TEXTURE2D(tex, int2)` 直接按整数像素坐标读取，不做插值、不需要采样器。所有 RT 尺寸相同，同一个像素编号在各张 RT 上对应同一个位置。
- 这里要求四张 RT 与最终目标的像素布局一致。整数读取省掉了归一化 UV 换算，但不会自动解决 XR 纹理数组、不同 viewport、动态分辨率或平台方向差异；迁移时仍要验证同一像素编号对应同一表面位置。

### 18.4 第 1 段：非 SSS 像素直接返回

```hlsl
float4 param = LOAD_TEXTURE2D(_SSSParamRT, pixel);
if (param.a <= 0) return float4(centerIrradiance, 0);
```

遮罩为 0 说明这里不是 SSS 物体，不用算。

### 18.5 第 2 段：单位换算与采样数

```hlsl
float3 d = max(param.rgb, 1e-4);
float dMax = max(d.r, max(d.g, d.b));

float centerZ = LoadLinearDepth(pixel);
float metersPerPixel = centerZ * _SSSParams.x;
float pixelsPerMm = 1.0 / (metersPerPixel * 1000.0);

float filterRadius = BURLEY_X_AT_CDF_0997 * dMax;
float filterRadiusPx = filterRadius * pixelsPerMm;
float filterArea = PI * filterRadiusPx * filterRadiusPx;
uint n = min((uint)(filterArea / SSS_PIXELS_PER_SAMPLE), (uint)_SSSParams.y);
if (n < 1) return float4(centerIrradiance, 1);
```

| 代码 | 理论 |
|---|---|
| `max(param.rgb, 1e-4)` | 防止后面 `r / d` 除以 0 |
| `LoadLinearDepth` | 对普通透视深度使用 `LinearEyeDepth`，得到视轴线性深度；本地按 1 单位为 1 米换算 |
| `metersPerPixel`、`pixelsPerMm` | 第 12.1 节 |
| `BURLEY_X_AT_CDF_0997 * dMax` | 第 11.3 节，$16.56\, d_{max}$ |
| `n = min(面积 / 4, 预算)` | 第 11.4 节 |

**数值例子**：$d_{max} = 5$ mm，物体在 3 m 处，fovY = 60°，1920×1080：

- $\frac{2}{P_{00}\cdot\text{width}} \approx 0.00107$，metersPerPixel $\approx 0.0032$，pixelsPerMm $\approx 0.31$
- 估计半径 $=82.8$ mm，约 26 像素；估计面积约 2100 像素，除以 4 约 525，受预算 32 限制后 $N=32$。这只决定执行 32 次采样；实际最外半径约 $11.61\times5=58.1$ mm，不是 82.8 mm。

### 18.6 第 3 段：采样循环

```hlsl
int2 maxPixel = int2(_SSSParams.zw) - 1;
float phase = TWO_PI * PixelNoise(i.positionCS.xy);

float3 totalIrradiance = 0;
float3 totalWeight = 0;
for (uint k = 0; k < n; k++)
{
    float r, rcpPdf;
    SampleBurley((k + 0.5) / n, dMax, r, rcpPdf);

    float theta = phase + k * GOLDEN_ANGLE;
    float2 offset = r * pixelsPerMm * float2(cos(theta), sin(theta));
    int2 samplePixel = clamp(pixel + int2(round(offset)), int2(0, 0), maxPixel);

    if (LOAD_TEXTURE2D(_SSSParamRT, samplePixel).a <= 0) continue;

    float3 irradiance = LOAD_TEXTURE2D(_BlitTexture, samplePixel).rgb;
    float dzMm = (LoadLinearDepth(samplePixel) - centerZ) * 1000.0;
    float r3D = sqrt(r * r + dzMm * dzMm);

    float3 w = BurleyTimesR(r3D, d) * rcpPdf;
    totalIrradiance += w * irradiance;
    totalWeight += w;
}
```

| 代码 | 理论 |
|---|---|
| `PixelNoise` | Interleaved Gradient Noise，一个用像素坐标算伪随机数的公式，相邻像素的值差异大且分布均匀 |
| `(k + 0.5) / n` | 第 11.1 节分层采样的 $u_k$ |
| `SampleBurley(u, dMax, r, rcpPdf)` | 第 10 节：用 $d_{max}$ 解逆 CDF 得到 $r_k$ 和 $1/q$ |
| `phase + k * GOLDEN_ANGLE` | 第 11.2 节 |
| `r * pixelsPerMm * (cos, sin)` | 毫米 → 像素偏移 |
| `clamp(...)` | 防止读到 RT 外面 |
| `.a <= 0 → continue` | 第 12.3 节遮罩：丢弃非 SSS 样本 |
| `r3D = sqrt(r² + dz²)` | 第 12.2 节双边距离（深度差从米换成毫米） |
| `BurleyTimesR(r3D, d) * rcpPdf` | 第 9.3 节权重 $w_{k,c}$，三个通道用各自的 $d_c$ |

`BurleyTimesR` 就是 $R(r)\cdot r$：

```hlsl
float3 BurleyTimesR(float r, float3 d)
{
    return (exp(-r / d) + exp(-r / (3.0 * d))) / (8.0 * PI * d);
}
```

`d` 是 `float3`，所以指数和除法逐通道执行，一次得到 RGB 权重。循环中 `d` 始终来自中心：邻居参数只读取 alpha，不读取邻居 RGB 距离。因此它是“用出口的核混合周围输入”，没有模拟不同介质之间完整的双向传输。

再跟一次样本的生命周期：`SampleBurley` 返回连续半径及其原始 pdf；偏移被 `round` 到整数像素，再由 `clamp` 限制边界；读该像素深度得到 $r'$；最后把 $K(r')/q$ 同时加进亮度分子和权重分母。权重使用的 $r$ 仍是生成时的连续半径，没有按取整后的像素重新计算。因此像素化、重复采样和边界夹取也是这份离散实现的近似来源。

### 18.7 第 4 段：归一化输出

```hlsl
float3 result = totalWeight > 1e-5 ? totalIrradiance / totalWeight : centerIrradiance;
return float4(result, 1);
```

- 第 9.4 节的逐通道自归一化。比如红通道累积亮度为 8、权重为 0.8，返回 10；绿通道使用自己的分子与分母，不共用红色权重。
- 某通道权重小于阈值时，退回中心输入，避免除零或把极小权重放大成不稳定结果。原因可能是有效样本不足，也可能是窄通道在现有采样位置的权重已衰减得很小。
- 代码保留源码的向量条件表达式，意图是逐通道回退。若要更明确地表达，可以把 `result.r/g/b` 分别写成标量条件；这属于等价的代码表达选择，本文没有替换源码。

## 19. 步骤四：前向 Pass 合成

文件：`Assets/SSS-TEST/SSSBurley/SSSBurleyLit.shader`，Pass `ForwardComposite`。

### 19.1 目的

对应第 13 节最后一步：$\sqrt{\rho(p_o)}$ 乘散射结果，再加高光。比如均匀灰色表面 $\rho=0.36$、$D=10$，预绘制存入 $0.6\times10=6$；均匀输入滤波后仍为 6；出口再乘 0.6，得到 3.6，恰好是 $\rho D$。若这里忘乘，物体会偏亮；若又叠加普通漫反射，则会重复计算漫反射。

### 19.2 实现

```hlsl
Pass
{
    Name "ForwardComposite"
    Tags { "LightMode" = "UniversalForward" }
    ...
    TEXTURE2D(_SSSResultRT);

    half4 frag(Varyings i) : SV_Target
    {
        half3 albedo = SampleAlbedo(i.uv);
        ...
        half3 specular = brdfData.specular * DirectBRDFSpecular(brdfData, n, light.direction, v) * radiance;
        ...
        half3 indirectSpecular = GlossyEnvironmentReflection(...) * EnvironmentBRDFSpecular(brdfData, fresnelTerm);

        half3 scattered = LOAD_TEXTURE2D(_SSSResultRT, int2(i.positionCS.xy)).rgb;
        return half4(scattered * sqrt(albedo) + specular + indirectSpecular, 1);
    }
}
```

- `LightMode = UniversalForward`：URP 画不透明物体时会自动画这个 Pass。
- 高光复用 URP 的 `BRDFData`、`DirectBRDFSpecular` 与 `GlossyEnvironmentReflection` 等函数，但这里只计算主光源高光和环境反射，不等于完整 Lit 全部功能。第 16 节漫反射扣除使用固定 `SKIN_F0=0.028`，这里却通过 `InitializeBRDFData` 获取表面 BRDF 参数，没有显式让两者共享该常量；不能据此声称已完成严格一致的反射/透射能量配平。
- `scattered * sqrt(albedo)`：第 6 节模糊后的那一半 albedo。
- 用 `int2(i.positionCS.xy)` 读结果：步骤三的 RT 和相机目标尺寸一致，同一像素坐标对应同一位置。

### 19.3 为什么在前向 Pass 里合成，而不是最后全屏叠加

另一种组织方式是在不透明物体之后全屏 `Blend One One` 叠加。这样需要另外回答两个问题：

1. 如果 SSS 物体被别的物体挡住，全屏叠加仍然会把它的漫反射加到挡在前面的物体上，必须额外做深度比较。
2. 后乘的那一半 $\sqrt{\rho}$ 需要每个像素的 albedo，全屏 Pass 里拿不到，还得多存一张图。

在前向 Pass 里读结果，最终可见性由相机深度测试处理，albedo 也可直接从材质读取。不过，这只解决最终写到谁身上的问题：预滤波时缺少普通遮挡物深度，仍可能让遮挡后的 SSS 输入参与邻居混合。最终合成正确，不代表滤波阶段已经拥有完整场景可见性。

## 20. 使用、调参与调试

### 20.1 接入步骤

1. 在当前 URP Asset 或相机设置中确认实际使用的 Renderer，再打开对应资源，例如 `Assets/Settings/URP-HighFidelity-Renderer.asset`。修改未被相机使用的 Renderer 不会影响画面。
2. 在测试 Renderer 上停用其他 SSS Feature，避免同时执行不同管线。
3. 添加 `SSSBurleyFeature`，将 Filter Shader 指向 `Hidden/SSS/SSSBurleyFilter`。
4. 测试材质使用 `SSS/SSSBurleyLit`。不要只把 `SSSLit` 材质留在模型上再换 Feature：自定义 LightMode 必须与 Feature 的筛选标签相同。
5. 使用普通透视 Game 相机或 Scene 视图，确认模型尺寸按 1 单位为 1 米理解。先在简单不透明场景验证，再接入相机堆叠、XR 或不同分辨率路径。

### 20.2 用三组实验看懂结果

**先看常量保持。** 用白色或均匀灰色材质，让一片较平区域受到近似均匀光照。只调整 Scatter Distance，滤波后的这片区域不应仅因核变宽而持续变暗。这个实验检查前后颜色分配和权重归一化。

**再看扩散范围。** 用白光、白色 albedo，在表面制造明确阴影边缘。先令 Scatter Color 三通道相同，观察是否出现不带色的柔化；再改为红通道较宽，观察亮侧红光是否延伸到暗侧。比较 Diffuse RT 与 Result RT，比只看最终高光覆盖下的画面更容易判断。

**最后看纹理与高光。** 加入有细节的颜色贴图，观察前后平方根分配是否保留一定局部对比；调节 Smoothness，确认高光没有跟着漫反射核一起扩散。本地没有法线贴图接口，不能靠挂一张法线图验证细节散射；需要先扩展材质的法线读取。

### 20.3 一次只改变一类参数

| 参数 | 位置 | 作用 | 调节顺序 |
|---|---|---|---|
| Scatter Color | 材质 | RGB 散射距离的比例，不是直接染色 | 先用三个相同分量，再让某通道更宽 |
| Scatter Distance | 材质 | $d$ 的共同毫米尺度 | 先确认模型大小，再从小到大观察边界；夸张值只用于确认通路 |
| Sample Budget | Feature | 每像素循环次数上限，本地范围 4～64、默认 32 | 固定散射尺度后比较 16、32、64 的噪点与开销 |

预算增大不等于物理散射距离增大，但会改变有限采样图案以及最外分位点，因此画面不会与低预算版本完全相同。物体离相机远时，预算可能根本未用满，增加上限也不会增加实际读取次数。

### 20.4 顺着数据流定位问题

在 Frame Debugger 中找到 `SSS Burley` 对应事件，按写入顺序检查：

| 阶段 | 应看到什么 | 下一步定位 |
|---|---|---|
| MRT 预绘制 | Diffuse RGB 有受光表面，Param alpha 有轮廓 | 全无时先查相机、Feature、材质 LightMode 与剔除；只有光照黑时再查灯光、阴影和输入颜色 |
| 参数 RT | RGB 是毫米距离，alpha 为 1 | 默认值可超过 1，显示器预览会饱和；看数值，不能把预览颜色当作 albedo |
| 独立深度 | 同一 SSS 表面的深度变化 | 检查绑定与写入，比较线性化后的值；不要直接把原始深度当米数 |
| 滤波输出 | 阴影边缘改变，均匀区域基本保持 | 输入相同不必有变化；再检查实际 $N$、偏移取整、参数与有效样本 |
| 前向合成 | 局部颜色恢复，高光保持清晰 | 若与 Result 不对应，检查全局纹理发布、像素坐标和相机执行顺序 |

本地还有一个需要在使用深度/法线功能时留意的 Pass：它名为 `DepthOnly`，但 LightMode 写成 `DepthNormals`，片元只返回 `positionCS.z`，并没有输出正常的编码法线。SSS 自己的深度来自 MRT 预绘制，不依赖它；若接入 SSAO 或相机法线纹理，应单独修正这一功能，不能把它当作完整深度法线通路。

### 20.5 从现象回到原因

| 现象 | 先做的区分 | 处理方向 |
|---|---|---|
| 细碎噪点或花纹 | 固定距离，提高预算后是否改善 | 若改善，主要是采样误差；时间累积需同时验证相位变化与历史重投影 |
| 轮廓亮边或暗边 | 是屏幕边界、SSS mask 边界，还是深度断层 | 分别检查 clamp 重复读取、有效样本归一化和深度单位；不要只增大预算 |
| 两个物体互相串色 | 两者是否都写入 SSS mask、深度是否接近 | 增加对象/profile 隔离策略，或更完整的几何判据 |
| 远处效果不明显 | 实际 $N$ 是否为 0，偏移是否大多落回中心 | 屏幕分辨率限制属于正常退化；若近处也无变化，再查数据流 |
| 近处开销高 | 是更多像素参与，还是循环预算更高 | 先测预绘制和滤波各自耗时；样本读取带宽、半径导致的缓存局部性也会影响成本 |
| 耳朵背光仍不透亮 | 是否期待背面入射光 | 转向透射模型，不靠继续增大同侧滤波宽度 |

## 21. 进阶方向

### 21.1 先补齐输入，再增加散射复杂度

当前 $D$ 只含主光源和 SH 环境光。要支持附加光源，应在漫反射预绘制中按所用 URP 路径遍历灯光，将每盏灯的衰减、阴影和漫反射贡献累加进去；前向合成也要补上相应高光。仅增加滤波样本，不能补回没有写入 Diffuse RT 的灯光。

法线贴图也应在光照输入阶段接入，让它改变 $N\cdot L$ 与高光，而不是把最终颜色再做一次模糊。完成这些输入后，再检查 $F_0$ 等反射参数是否在两条光照路径中一致。

### 21.2 薄部位透射需要厚度

背光耳朵的问题是光从另一侧进入，要先获得光照方向上的厚度 $t$，例如使用厚度贴图或合适的光空间前后深度估计。$\max(0,-\mathbf n\cdot\omega_i)$ 只能描述背光朝向，是无量纲角度因子，不能拿来代替毫米厚度。

与 Burley 形状有关的一条衰减函数为：

$$
T(t)=\frac14\left(e^{-t/d}+3e^{-t/(3d)}\right).
$$

它与第 10 节的尾部累计量 $1-C(t)$ 同形，满足 $T(0)=1$、随厚度增大趋于 0。这个函数可以帮助构造薄层透射近似，但单独一个 $T$ 还不是完整透射着色：仍需背面入射光、颜色、边界项和可靠厚度。还要决定透射是否进入后续扩散，避免先使用已拟合的透射分布，又无条件模糊一次。当前三份源码没有实现这条路径。

### 21.3 用共享参数与可见性信息控制混合

把每像素 RGB 距离改成 profile 编号，可以让多个材质共享一组参数，减少重复参数存储；编号与 mask 仍需保存，是否真能省掉一张 RT，取决于能否打包进已有附件。profile 不同的邻居是否互相混合，也应成为显式规则。

如果主要问题是跨物体漏光，应优先补充场景深度、对象标识或法线判据。若需要改善倾斜表面，可在切平面生成偏移并投影回屏幕，但要同时处理采样密度与面积变换；只重建三维距离，还不足以得到严格的曲面积分。

### 21.4 让性能和降噪各有职责

非 SSS 像素现在也会运行全屏片元并读取 mask。可考虑 stencil 或分块筛选提前跳过无关区域；实现时需要把相应深度/stencil 附件正确绑定到滤波目标，不能只加一行 stencil 比较就假定全屏 Blit 能读取预绘制标记。

时间降噪则需要让相位随帧变化，并通过有效的运动矢量、历史重投影和遮挡拒绝累积结果。静态区域能借此积累更多采样，运动边缘却必须及时丢弃失效历史，否则会拖影。先把单帧的尺度、mask 与常量保持验证正确，再引入时间累积，才能分清错误来自空间滤波还是历史数据。

| 方面 | 之前（`SSSFilter.shader`） | 本教程（`SSSBurleyFilter.shader`） |
|---|---|---|
| 采样形状 | 横一遍、竖一遍（两次 1D） | 一次 2D 圆盘 |
| 样本分布 | 均匀 | 按 Burley 剖面重要性采样 |

| 噪点 | 无（规则采样） | 有少量噪点，需要 TAA |
